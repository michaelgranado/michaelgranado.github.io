Analysis of the Current Implementation

Looking at the current CUDA implementation in the kernelRenderCircles function, I can identify several issues that explain why it's not meeting the correctness requirements:

  1. Atomicity Violations: The current implementation lacks atomic operations when updating the image color values. Multiple threads can read and write to the same pixel simultaneously, causing race conditions and visual artifacts like the streaks mentioned in the assignment description.
  2. Order Violations: The circles are processed in batches, but within each batch, the circles are not necessarily processed in the input order. This violates the ordering requirement which states that for overlapping circles, their contributions must be applied in the input order.
  3. Performance Issues: The test results show the current implementation is much slower than the reference solution, especially for scenes with many circles (rand100k, rand1M, micro2M).

Strategy

To create a correct and efficient implementation, I'll develop a strategy that addresses both the atomicity and ordering requirements while maintaining high performance. Here's my approach:

  1. Sort by Pixel First: Rather than having each thread process circles for a fixed pixel, I'll use a more flexible approach that sorts work by pixel first.
  2. Use Per-Pixel Circle Lists: For each pixel, build a list of circles that potentially contribute to it.
  3. Process Lists in Order: Process these per-pixel lists in the correct input order to maintain the ordering requirement.
  4. Single Write Per Pixel: Accumulate all color contributions locally and write to global memory only once per pixel, ensuring atomicity.
  5. Optimize Memory Access: Use shared memory effectively to reduce global memory traffic and batch operations.
  6. Exploit Circle-Box Tests: Use the provided circle-box test aggressively to avoid unnecessary work.

Detailed Reasoning

The key insight is that we need to satisfy both the atomicity and ordering requirements simultaneously. The current approach of having each thread process a single pixel and looping through all circles makes it difficult to guarantee order, and the lack of atomic operations causes race conditions.

My strategy separates the rendering process into two primary phases:

  1. Circle-to-Pixel Mapping: First, determine which circles contribute to which pixels. This can be done by having each thread (or thread block) handle a circle and identify all pixels it affects.
  2. Pixel Rendering: Then, for each pixel, process all contributing circles in the correct order and write the final color to global memory once.

This approach has several advantages:

  • It naturally preserves order since we can sort the contributing circles by their input indices.
  • It eliminates race conditions by having a single thread write the final pixel color.
  • It reduces global memory operations by accumulating color locally before writing.
  • It enables better parallelism by mapping the problem to the GPU architecture more effectively.

The main challenge will be managing memory efficiently, especially for scenes with many circles. I'll need to use shared memory carefully and may need to process the scene in multiple passes for very large scenes.

// Data structure to store circle contributions to pixels
struct CircleContribution {
    int circleIndex;  // Index of the circle in global array
    float3 rgb;       // RGB color of the circle
    float alpha;      // Alpha value for blending
};

// First phase: Determine which circles contribute to which pixels
__global__ void kernelIdentifyActiveCircles(
    int* circleCountPerPixel,
    int* circleIndexPerPixel,
    int maxCirclesPerPixel) {
    
    // Calculate pixel coordinates
    int pixelX = blockIdx.x * blockDim.x + threadIdx.x;
    int pixelY = blockIdx.y * blockDim.y + threadIdx.y;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if pixel is in bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;

    // Calculate pixel center in normalized coordinates
    float invWidth = 1.0f / imageWidth;
    float invHeight = 1.0f / imageHeight;
    float2 pixelCenter = make_float2(invWidth * (static_cast(pixelX) + 0.5f),
                             invHeight * (static_cast(pixelY) + 0.5f));

    // Define the pixel's box for circle-box tests
    float boxL = invWidth * pixelX;
    float boxR = invWidth * (pixelX + 1);
    float boxB = invHeight * pixelY;
    float boxT = invHeight * (pixelY + 1);

    // Pixel offset in the global arrays
    int pixelOffset = pixelY * imageWidth + pixelX;
    
    // Initialize count of circles affecting this pixel
    int circleCount = 0;
    
    // Check each circle to see if it affects this pixel
    for (int i = 0; i < cuConstRendererParams.numCircles && circleCount < maxCirclesPerPixel; i++) {
        int index3 = 3 * i;
        
        // Load circle position and radius
        float3 p;
        p.x = cuConstRendererParams.position[index3];
        p.y = cuConstRendererParams.position[index3 + 1];
        p.z = cuConstRendererParams.position[index3 + 2];
        float rad = cuConstRendererParams.radius[i];
        
        // Quick circle-box test
        if (!circleInBoxConservative(p.x, p.y, rad, boxL, boxR, boxT, boxB))
            continue;
            
        // More precise test: check if pixel center is inside circle
        float diffX = p.x - pixelCenter.x;
        float diffY = p.y - pixelCenter.y;
        float pixelDist = diffX * diffX + diffY * diffY;
        float maxDist = rad * rad;
        
        if (pixelDist <= maxDist) {
            // Circle affects this pixel, store its index
            int idx = pixelOffset * maxCirclesPerPixel + circleCount;
            circleIndexPerPixel[idx] = i;
            circleCount++;
        }
    }
    
    // Store the count of circles for this pixel
    circleCountPerPixel[pixelOffset] = circleCount;
}

// Second phase: Render the circles for each pixel in the correct order
__global__ void kernelRenderCircles(
    int* circleCountPerPixel,
    int* circleIndexPerPixel,
    int maxCirclesPerPixel) {
    
    // Calculate pixel coordinates
    int pixelX = blockIdx.x * blockDim.x + threadIdx.x;
    int pixelY = blockIdx.y * blockDim.y + threadIdx.y;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if pixel is in bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;

    // Calculate pixel center in normalized coordinates
    float invWidth = 1.0f / imageWidth;
    float invHeight = 1.0f / imageHeight;
    float2 pixelCenter = make_float2(invWidth * (static_cast(pixelX) + 0.5f),
                             invHeight * (static_cast(pixelY) + 0.5f));

    // Pixel offset in the global arrays
    int pixelOffset = pixelY * imageWidth + pixelX;
    
    // Get the count of circles affecting this pixel
    int circleCount = circleCountPerPixel[pixelOffset];
    
    // Initialize pixel color
    float4 pixelColor;
    if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
        float shade = .4f + .45f * static_cast(imageHeight-pixelY) / imageHeight;
        pixelColor = make_float4(shade, shade, shade, 1.f);
    } else {
        pixelColor = make_float4(1.0f, 1.0f, 1.0f, 1.0f);
    }
    
    // Process circles in order, blending their contributions
    for (int i = 0; i < circleCount; i++) {
        int idx = pixelOffset * maxCirclesPerPixel + i;
        int circleIdx = circleIndexPerPixel[idx];
        int index3 = 3 * circleIdx;
        
        // Load circle position, radius, and color
        float3 p;
        p.x = cuConstRendererParams.position[index3];
        p.y = cuConstRendererParams.position[index3 + 1];
        p.z = cuConstRendererParams.position[index3 + 2];
        float rad = cuConstRendererParams.radius[circleIdx];
        
        // Calculate distance from pixel center to circle center
        float diffX = p.x - pixelCenter.x;
        float diffY = p.y - pixelCenter.y;
        float pixelDist = diffX * diffX + diffY * diffY;
        float maxDist = rad * rad;
        
        // Compute color contribution for this circle
        float3 rgb;
        float alpha;
        
        if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
            const float kCircleMaxAlpha = .5f;
            const float falloffScale = 4.f;

            float normPixelDist = sqrt(pixelDist) / rad;
            rgb = lookupColor(normPixelDist);

            float maxAlpha = .6f + .4f * (1.f-p.z);
            maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f);
            alpha = maxAlpha * exp(-1.f * falloffScale * normPixelDist * normPixelDist);
        } else {
            rgb.x = cuConstRendererParams.color[index3];
            rgb.y = cuConstRendererParams.color[index3 + 1];
            rgb.z = cuConstRendererParams.color[index3 + 2];
            alpha = .5f;
        }
        
        // Blend color contribution
        float oneMinusAlpha = 1.f - alpha;
        pixelColor.x = alpha * rgb.x + oneMinusAlpha * pixelColor.x;
        pixelColor.y = alpha * rgb.y + oneMinusAlpha * pixelColor.y;
        pixelColor.z = alpha * rgb.z + oneMinusAlpha * pixelColor.z;
        pixelColor.w = alpha + pixelColor.w;
    }
    
    // Write final pixel color to output
    int offset = 4 * pixelOffset;
    cuConstRendererParams.imageData[offset] = pixelColor.x;
    cuConstRendererParams.imageData[offset + 1] = pixelColor.y;
    cuConstRendererParams.imageData[offset + 2] = pixelColor.z;
    cuConstRendererParams.imageData[offset + 3] = pixelColor.w;
}

// Optimized version that uses shared memory efficiently
__global__ void kernelRenderCirclesOptimized() {
    // Shared memory for circle data caching
    __shared__ float3 sharedPos[CIRCLES_PER_THREAD_BLOCK];
    __shared__ float sharedRad[CIRCLES_PER_THREAD_BLOCK];
    __shared__ float3 sharedCol[CIRCLES_PER_THREAD_BLOCK];
    
    // Calculate pixel coordinates
    int pixelX = blockIdx.x * blockDim.x + threadIdx.x;
    int pixelY = blockIdx.y * blockDim.y + threadIdx.y;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if pixel is in bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;

    // Calculate pixel center in normalized coordinates
    float invWidth = 1.0f / imageWidth;
    float invHeight = 1.0f / imageHeight;
    float2 pixelCenter = make_float2(invWidth * (static_cast(pixelX) + 0.5f),
                             invHeight * (static_cast(pixelY) + 0.5f));

    // Define the pixel's box for circle-box tests
    float boxL = invWidth * pixelX;
    float boxR = invWidth * (pixelX + 1);
    float boxB = invHeight * pixelY;
    float boxT = invHeight * (pixelY + 1);

    // Initialize pixel color
    float4 pixelColor;
    if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
        float shade = .4f + .45f * static_cast(imageHeight-pixelY) / imageHeight;
        pixelColor = make_float4(shade, shade, shade, 1.f);
    } else {
        pixelColor = make_float4(1.0f, 1.0f, 1.0f, 1.0f);
    }
    
    // Local buffer for circle contributions
    CircleContribution circleContributions[MAX_CIRCLES_PER_PIXEL];
    int circleCount = 0;
    
    // Process circles in batches
    int numCircles = cuConstRendererParams.numCircles;
    for (int circleStart = 0; circleStart < numCircles; circleStart += CIRCLES_PER_THREAD_BLOCK) {
        int circlesInBatch = min(CIRCLES_PER_THREAD_BLOCK, numCircles - circleStart);
        
        // Collaborative loading of circle data
        int linearThreadIndex = threadIdx.y * blockDim.x + threadIdx.x;
        int totalThreads = blockDim.x * blockDim.y;
        
        for (int i = linearThreadIndex; i < circlesInBatch; i += totalThreads) {
            int globalCircleIndex = circleStart + i;
            int index3 = 3 * globalCircleIndex;
            
            // Load position
            sharedPos[i].x = cuConstRendererParams.position[index3];
            sharedPos[i].y = cuConstRendererParams.position[index3 + 1];
            sharedPos[i].z = cuConstRendererParams.position[index3 + 2];
            
            // Load radius
            sharedRad[i] = cuConstRendererParams.radius[globalCircleIndex];
            
            // Load color
            sharedCol[i].x = cuConstRendererParams.color[index3];
            sharedCol[i].y = cuConstRendererParams.color[index3 + 1];
            sharedCol[i].z = cuConstRendererParams.color[index3 + 2];
        }
        
        __syncthreads(); // Ensure all circle data is loaded
        
        // Check each circle in the batch for contribution to this pixel
        for (int i = 0; i < circlesInBatch && circleCount < MAX_CIRCLES_PER_PIXEL; i++) {
            int globalCircleIndex = circleStart + i;
            
            // Quick circle-box test
            if (!circleInBoxConservative(sharedPos[i].x, sharedPos[i].y, sharedRad[i], boxL, boxR, boxT, boxB))
                continue;
                
            // More precise test: check if pixel center is inside circle
            float diffX = sharedPos[i].x - pixelCenter.x;
            float diffY = sharedPos[i].y - pixelCenter.y;
            float pixelDist = diffX * diffX + diffY * diffY;
            float maxDist = sharedRad[i] * sharedRad[i];
            
            if (pixelDist <= maxDist) {
                // Calculate color contribution
                CircleContribution contribution;
                contribution.circleIndex = globalCircleIndex;
                
                if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
                    const float kCircleMaxAlpha = .5f;
                    const float falloffScale = 4.f;

                    float normPixelDist = sqrt(pixelDist) / sharedRad[i];
                    contribution.rgb = lookupColor(normPixelDist);

                    float maxAlpha = .6f + .4f * (1.f-sharedPos[i].z);
                    maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f);
                    contribution.alpha = maxAlpha * exp(-1.f * falloffScale * normPixelDist * normPixelDist);
                } else {
                    contribution.rgb = sharedCol[i];
                    contribution.alpha = .5f;
                }
                
                // Store the contribution
                circleContributions[circleCount++] = contribution;
            }
        }
        
        __syncthreads(); // Ensure all threads are done with this batch
    }
    
    // Apply all circle contributions in order
    for (int i = 0; i < circleCount; i++) {
        float3 rgb = circleContributions[i].rgb;
        float alpha = circleContributions[i].alpha;
        
        // Blend color contribution
        float oneMinusAlpha = 1.f - alpha;
        pixelColor.x = alpha * rgb.x + oneMinusAlpha * pixelColor.x;
        pixelColor.y = alpha * rgb.y + oneMinusAlpha * pixelColor.y;
        pixelColor.z = alpha * rgb.z + oneMinusAlpha * pixelColor.z;
        pixelColor.w = alpha + pixelColor.w;
    }
    
    // Write final pixel color to output
    int offset = 4 * (pixelY * imageWidth + pixelX);
    cuConstRendererParams.imageData[offset] = pixelColor.x;
    cuConstRendererParams.imageData[offset + 1] = pixelColor.y;
    cuConstRendererParams.imageData[offset + 2] = pixelColor.z;
    cuConstRendererParams.imageData[offset + 3] = pixelColor.w;
}

    }

void
CudaRenderer::setup() {

    int deviceCount = 0;
    std::string name;
    cudaError_t err = cudaGetDeviceCount(&deviceCount);

    printf("---------------------------------------------------------\n");
    printf("Initializing CUDA for CudaRenderer\n");
    printf("Found %d CUDA devices\n", deviceCount);

    for (int i=0; i(deviceProps.totalGlobalMem) / (1024 * 1024));
        printf("   CUDA Cap:   %d.%d\n", deviceProps.major, deviceProps.minor);
    }
    printf("---------------------------------------------------------\n");
    
    // By this time the scene should be loaded.  Now copy all the key
    // data structures into device memory so they are accessible to
    // CUDA kernels
    //
    // See the CUDA Programmer's Guide for descriptions of
    // cudaMalloc and cudaMemcpy

    cudaCheckError(cudaMalloc(&cudaDevicePosition, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceVelocity, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceColor, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceRadius, sizeof(float) * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceImageData, sizeof(float) * 4 * image->width * image->height));

    cudaCheckError(cudaMemcpy(cudaDevicePosition, position, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceVelocity, velocity, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceColor, color, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceRadius, radius, sizeof(float) * numCircles, cudaMemcpyHostToDevice));
    
    // Allocate additional buffers for the optimized renderer
    int pixelCount = image->width * image->height;
    cudaCheckError(cudaMalloc(&circleCountPerPixel, sizeof(int) * pixelCount));
    cudaCheckError(cudaMalloc(&circleIndexPerPixel, sizeof(int) * pixelCount * MAX_CIRCLES_PER_PIXEL));

    // Initialize parameters in constant memory.  We didn't talk about
    // constant memory in class, but the use of read-only constant
    // memory here is an optimization over just sticking these values
    // in device global memory.  NVIDIA GPUs have a few special tricks
    // for optimizing access to constant memory.  Using global memory
    // here would have worked just as well.  See the Programmer's
    // Guide for more information about constant memory.

    GlobalConstants params;
    params.sceneName = sceneName;
    params.numCircles = numCircles;
    params.imageWidth = image->width;
    params.imageHeight = image->height;
    params.position = cudaDevicePosition;
    params.velocity = cudaDeviceVelocity;
    params.color = cudaDeviceColor;
    params.radius = cudaDeviceRadius;
    params.imageData = cudaDeviceImageData;

    cudaCheckError(cudaMemcpyToSymbol(cuConstRendererParams, ¶ms, sizeof(GlobalConstants)));

    // also need to copy over the noise lookup tables, so we can
    // implement noise on the GPU
    int* permX;
    int* permY;
    float* value1D;
    getNoiseTables(&permX, &permY, &value1D);
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseXPermutationTable, permX, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseYPermutationTable, permY, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoise1DValueTable, value1D, sizeof(float) * 256));

    // last, copy over the color table that's used by the shading
    // function for circles in the snowflake demo

    float lookupTable[COLOR_MAP_SIZE][3] = {
        {1.f, 1.f, 1.f},
        {1.f, 1.f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, 0.8f, 1.f},
    };

    cudaCheckError(cudaMemcpyToSymbol(cuConstColorRamp, lookupTable, sizeof(float) * 3 * COLOR_MAP_SIZE));
}

// clearImage --
//
// Clear's the renderer's target image.  The state of the image after
// the clear depends on the scene being rendered.
void
CudaRenderer::clearImage() {

    // 256 threads per block is a healthy number
    dim3 blockDim(16, 16, 1);
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
        kernelClearImageSnowflake<<>>();
    } else {
        kernelClearImage<<>>(1.f, 1.f, 1.f, 1.f);
    }
    cudaCheckError(cudaDeviceSynchronize());
}
