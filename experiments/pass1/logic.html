1) Detailed Strategy

We need to ensure two correctness guarantees for semitransparent circle rendering in parallel:

  1. Atomicity: The update of a single pixel with the contribution from a circle must not race with other writes. These writes must not happen out of order or interleave in incorrect ways.
  2. Ordering: If circle A precedes circle B in the circle array, and both circles affect the same pixel, then circle A’s contribution must be blended before circle B’s contribution.

A straightforward approach that meets both correctness requirements is to parallelize across pixels rather than circles. Each pixel has exactly one thread responsible for blending in the contributions from all circles in their listed order. This prevents any need for atomic operations, because for any pixel, only one thread writes its final color. The circle array is processed in the original order, ensuring correct layering of semitransparent circles.

Hence, the plan is:

  1. Keep the existing code that sets up the device, transfers data, and clears the image in the background color (snow gradient or white).
  2. Create a new kernel that launches one CUDA thread per pixel. Each thread (for a specific pixel) will do a loop over all circles in order. If the pixel center is inside a circle, blend the circle’s color into an intermediate color. At the end, store the final blended color into the global frame buffer.
  3. Because each pixel is handled by exactly one thread, we avoid data races on that pixel’s color, and the order of circles is naturally preserved by an inner loop from circle 0 up to circle N-1.
  4. At kernel completion, the final correct image is ready, so we can safely copy it to the CPU if needed.

2) Detailed Reasoning

Using a pixel-centric approach resolves the atomicity and ordering constraints easily:

  • No atomic needed: Only one thread writes to a given pixel, so we do not need to protect those stores against races.
  • Built-in ordering: Within each thread, we process circles from index 0 up to numCircles-1 in the provided order. That ensures that if circle i is before circle j in the array, circle i’s contribution is blended first.

Although this solution may be slow for large numbers of circles, the instructions say to focus on correctness rather than efficiency, making it an acceptable approach.

// ---------------------------------------------------------------------------
// Device helper: Color blending for a pixel with circle's RGBA
// ---------------------------------------------------------------------------

__device__ __inline__ void blendCircleColor(
    int circleIndex,
    float2 pixelCenterNorm,
    float sceneZ,
    float4 &accumulatedColor)
{
    float* pos = cuConstRendererParams.position;
    float* col = cuConstRendererParams.color;
    float* rad = cuConstRendererParams.radius;

    float3 circlePos = *((float3*)(&pos[3*circleIndex]));
    float  radius    = rad[circleIndex];

    // Distance check
    float diffX = circlePos.x - pixelCenterNorm.x;
    float diffY = circlePos.y - pixelCenterNorm.y;
    float pixelDist2 = diffX*diffX + diffY*diffY; 
    float radius2    = radius * radius;
    if (pixelDist2 > radius2) {
        // Pixel not inside this circle
        return;
    }

    float alpha;
    float3 rgb;

    // For SNOWFLAKES or SNOWFLAKES_SINGLE_FRAME, we do the special color ramp
    if (cuConstRendererParams.sceneName == SNOWFLAKES ||
        cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {

        const float kCircleMaxAlpha = 0.5f;
        const float falloffScale    = 4.f;
        float normDist = sqrtf(pixelDist2) / radius;
        rgb = lookupColor(normDist);

        float maxAlpha = 0.6f + 0.4f*(1.f - circlePos.z);
        // clamp, then scale
        if (maxAlpha < 0.f)  maxAlpha = 0.f;
        if (maxAlpha > 1.f)  maxAlpha = 1.f;
        maxAlpha = kCircleMaxAlpha * maxAlpha;
        alpha    = maxAlpha * __expf(- falloffScale * normDist * normDist);
    } 
    else {
        // Each circle has assigned color
        int index3 = 3*circleIndex;
        rgb.x      = col[index3    ];
        rgb.y      = col[index3 + 1];
        rgb.z      = col[index3 + 2];
        alpha      = 0.5f;  // per instructions
    }

    // The usual alpha-blending:
    float4 existing = accumulatedColor;
    float  oneMinusAlpha = 1.f - alpha;

    float4 newColor;
    newColor.x = alpha * rgb.x + oneMinusAlpha * existing.x;
    newColor.y = alpha * rgb.y + oneMinusAlpha * existing.y;
    newColor.z = alpha * rgb.z + oneMinusAlpha * existing.z;
    newColor.w = alpha + existing.w;

    accumulatedColor = newColor;
}

// ---------------------------------------------------------------------------
// Kernel: One thread per pixel (x,y).
// Loops over all circles in the original order, blending them if in range.
// ---------------------------------------------------------------------------

__global__ void kernelRenderCircles() 
{
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    int width  = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height)
        return;

    // Compute offset into image buffer
    int offset = 4 * (imageY * width + imageX);

    // Read the current pixel color (the image was pre-cleared)
    float4 pixelColor = *((float4*)(&cuConstRendererParams.imageData[offset]));

    // We'll convert (x,y) to [0,1] for the distance checks
    float invWidth  = 1.f / width;
    float invHeight = 1.f / height;

    float2 pixelCenterNorm = make_float2(
        invWidth  * (static_cast(imageX) + 0.5f),
        invHeight * (static_cast(imageY) + 0.5f));

    // Loop over circles in order, blending
    int numCircles = cuConstRendererParams.numCircles;
    for (int c = 0; c < numCircles; c++) {
        blendCircleColor(c, pixelCenterNorm, 0.f, pixelColor);
    }

    // Store final color back
    *((float4*)(&cuConstRendererParams.imageData[offset])) = pixelColor;
}

__global__ void kernelClearImageSnowflake() {
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    int width  = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height) return;

    int offset = 4 * (imageY * width + imageX);
    float shade = .4f + .45f * static_cast(height - imageY) / height; 
    float4 value = make_float4(shade, shade, shade, 1.f);

    *((float4*)(&cuConstRendererParams.imageData[offset])) = value;
}

__global__ void kernelClearImage(float r, float g, float b, float a) {
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;

    int width  = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height) return;

    int offset = 4 * (imageY * width + imageX);
    float4 value = make_float4(r, g, b, a);
    *((float4*)(&cuConstRendererParams.imageData[offset])) = value;

void CudaRenderer::clearImage() {
    dim3 blockDim(16,16);
    dim3 gridDim(
        (image->width  + blockDim.x - 1)/blockDim.x,
        (image->height + blockDim.y - 1)/blockDim.y);

    if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
        kernelClearImageSnowflake<<>>();
    } else {
        kernelClearImage<<>>(1.f,1.f,1.f,1.f);
    }
    cudaDeviceSynchronize();
}

void CudaRenderer::advanceAnimation() {
    // If needed, advance circle positions according to current scene
    dim3 blockDim(256);
    dim3 gridDim((numCircles + blockDim.x - 1)/blockDim.x);

    if (sceneName == SNOWFLAKES) {
        kernelAdvanceSnowflake<<>>();
    } else if (sceneName == BOUNCING_BALLS) {
        kernelAdvanceBouncingBalls<<>>();
    } else if (sceneName == HYPNOSIS) {
        kernelAdvanceHypnosis<<>>();
    } else if (sceneName == FIREWORKS) {
        kernelAdvanceFireWorks<<>>();
    }
    cudaDeviceSynchronize();
}

void CudaRenderer::render() {
    dim3 blockDim(16,16);
    dim3 gridDim(
        (image->width  + blockDim.x - 1)/blockDim.x,
        (image->height + blockDim.y - 1)/blockDim.y);

    kernelRenderCircles<<>>();
    cudaDeviceSynchronize();
}

In this modified code:

  • kernelRenderCircles is replaced with a kernel that launches one thread per pixel. Each thread loops over every circle in ascending order, blending each circle’s color (if the pixel center is within the circle’s boundary).
  • Because the pixel is only updated by the single thread that owns it, we do not need atomic operations, and the order of circles is trivially respected by the simple for-loop from 0 to numCircles-1.

This ensures correct semitransparent layering for all test scenes, satisfying the project’s correctness requirements.
