<h1>CUDA Renderer Optimization Strategy</h1>

<section>
  <h2>Strategy</h2>
  <p>
    The core performance bottleneck in the previous tile-based approach (`kernelRenderTileCentric`) was that every tile's thread block redundantly iterated through and loaded data (positions, radii) for all circle chunks, even those far outside the tile. While shared memory reduced accesses *within* a chunk iteration, the sheer number of chunks processed per tile, especially for scenes with many circles, led to poor performance.
  </p>
  <p>
    The optimized strategy focuses on drastically reducing the number of circles each tile needs to consider by implementing a <strong>two-pass approach with tile-specific circle lists</strong>:
  </p>
  <ol>
    <li>
      <strong>Pass 1: Build Tile-Circle Intersection Lists (Preprocessing Kernels):</strong>
      <ul>
        <li><strong>Identify Intersections:</strong> Launch a kernel (`kernelCountTileIntersections`) where threads (parallelizing over circles) determine which tiles each circle <em>conservatively</em> intersects using `circleInBoxConservative`. Atomically count the number of intersecting circles for each tile.</li>
        <li><strong>Determine Offsets:</strong> Perform a prefix sum (using Thrust for simplicity and efficiency) on the per-tile counts to calculate the starting offset for each tile's list within a large global array (`d_tileCircleLists`) that will store all intersection indices. This also gives the total number of intersections across all tiles.</li>
        <li><strong>Generate Intersection Pairs:</strong> Launch a second kernel (`kernelGeneratePairs`) where threads (again parallelizing over circles) find intersecting tiles. Using atomic operations based on the calculated offsets, each thread writes `{circleIndex, tileId}` pairs into a global buffer (`d_circleTilePairs`). At this stage, the pairs for a given tile are not necessarily sorted by `circleIndex`.</li>
        <li><strong>Sort for Order:</strong> Use `thrust::sort_by_key` to sort the `d_circleTilePairs` buffer. The primary sort key is `tileId`, and the secondary sort key is `circleIndex`. This step is <strong>crucial</strong> for maintaining the required rendering order.</li>
        <li><strong>Extract Sorted Indices:</strong> Launch a simple kernel or use `thrust::transform` to populate the final `d_tileCircleLists` array by extracting the `circleIndex` from the now-sorted pairs buffer. The `d_tileListOffsets` computed earlier directly map to this sorted list.</li>
      </ul>
    </li>
    <li>
      <strong>Pass 2: Render using Tile Lists (Optimized Rendering Kernel):</strong>
      <ul>
        <li><strong>Kernel Launch:</strong> Launch the main rendering kernel (`kernelRenderTilesFromLists`), assigning one thread block per image tile (e.g., 16x16) and one thread per pixel within the tile.</li>
        <li><strong>Targeted Circle Processing:</strong> Each thread determines its tile ID. Using the pre-computed `d_tileListOffsets`, it finds the start and end indices for its tile in `d_tileCircleLists`.</li>
        <li><strong>Iteration:</strong> The thread iterates <em>only</em> through the circle indices specified in `d_tileCircleLists` for its tile.</li>
        <li><strong>Data Fetching:</strong> For each `circleIndex` obtained from the list, the thread fetches the required circle data (position, radius, color) directly from global device memory (`cuConstRendererParams.position`, etc.). Shared memory is <em>not</em> used for circle data in this kernel to simplify the logic, relying instead on the drastically reduced number of circles being processed per tile.</li>
        <li><strong>Pixel Test & Blend:</strong> Perform the precise point-in-circle test for the thread's pixel center against the current circle. If the pixel is covered, calculate the circle's color/alpha contribution and blend it into a per-thread register accumulator.</li>
        <li><strong>Final Write:</strong> After processing all relevant circles from the tile's list, the thread writes its final accumulated color to the corresponding pixel in the global image buffer (`cuConstRendererParams.imageData`).</li>
      </ul>
    </li>
  </ol>
</section>

<section>
  <h2>Reasoning</h2>
  <p>
    This strategy directly targets the primary inefficiency of the previous approach: redundant work.
  </p>
  <ul>
    <li><strong>Reduced Circle Checks:</strong> By pre-calculating which circles might intersect which tiles, the main rendering kernel avoids iterating through the vast majority of circles that are irrelevant to a given tile. This significantly reduces computation, especially the number of distance checks and conditional branches.</li>
    <li><strong>Reduced Global Memory Traffic:</strong> Although the rendering kernel now reads circle data directly from global memory without using shared memory for caching circle pos/rad, it performs these reads far less often because it only considers circles known to be near the tile. The preprocessing phase introduces new global memory accesses, but the goal is that the cost of preprocessing plus the cost of rendering with reduced reads is significantly less than the cost of the previous approach's redundant reads across all tiles.</li>
    <li><strong>Maintaining Correctness:</strong>
      <ul>
        <li><strong>Atomicity:</strong> Preserved because each pixel's color calculation (read initial color, accumulate contributions, write final color) is still handled entirely by a single thread.</li>
        <li><strong>Order:</strong> Preserved by the crucial sorting step (`thrust::sort_by_key` on `{tileId, circleIndex}` pairs) during the list construction phase. This ensures that when the rendering kernel iterates through `d_tileCircleLists` for a specific tile, it processes the contributing circles in their original ascending index order, satisfying the blending requirement.</li>
      </ul>
    </li>
    <li><strong>Load Balancing:</strong> While this strategy still assigns blocks statically to tiles, the *work* performed by each block is now much more proportional to the actual rendering complexity within that tile (number of circle overlaps). Blocks covering empty regions do minimal work in the rendering kernel (iterating an empty list), while blocks covering dense regions process only the relevant circles. This implicitly improves load balancing compared to all blocks processing all circle chunks.</li>
    <li><strong>Feasibility:</strong> This approach uses standard CUDA patterns (atomic operations, prefix sums) and leverages the powerful Thrust library for sorting and scanning, making the implementation feasible. It avoids the potentially extreme memory requirements or complex synchronization of some alternative strategies like fragment generation/sorting. The necessary intermediate buffers are sized based on the actual number of intersections calculated in the first kernel, making memory allocation more manageable than worst-case estimations.</li>
  </ul>
</section>

__global__ void kernelClearImageSnowflake() {
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;
    int width = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    int offset = 4 * (imageY * width + imageX);
    float shade = .4f + .45f * static_cast<float>(height-imageY) / height;
    float4 value = make_float4(shade, shade, shade, 1.f);
    *(float4*)(&cuConstRendererParams.imageData[offset]) = value;
}

// kernelAdvanceFireWorks, kernelAdvanceHypnosis, kernelAdvanceBouncingBalls, kernelAdvanceSnowflake

__global__ void kernelAdvanceFireWorks() {
    const float dt = 1.f / 60.f;
    const float pi = 3.14159;
    const float maxDist = 0.25f;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;
    float* radius = cuConstRendererParams.radius;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;
    if (0 <= index && index < NUM_FIREWORKS) { // firework center; no update
        return;
    }
    // determine the fire-work center/spark indices
    int fIdx = (index - NUM_FIREWORKS) / NUM_SPARKS;
    int sfIdx = (index - NUM_FIREWORKS) % NUM_SPARKS;

    int index3i = 3 * fIdx;
    int sIdx = NUM_FIREWORKS + fIdx * NUM_SPARKS + sfIdx;
    int index3j = 3 * sIdx;

    float cx = position[index3i];
    float cy = position[index3i+1];

    // update position
    position[index3j] += velocity[index3j] * dt;
    position[index3j+1] += velocity[index3j+1] * dt;

    // fire-work sparks
    float sx = position[index3j];
    float sy = position[index3j+1];

    // compute vector from firework-spark
    float cxsx = sx - cx;
    float cysy = sy - cy;

    // compute distance from fire-work
    float dist = sqrt(cxsx * cxsx + cysy * cysy);
    if (dist > maxDist) { // restore to starting position
        // random starting position on fire-work's rim
        float angle = (sfIdx * 2 * pi)/NUM_SPARKS;
        float sinA = sin(angle);
        float cosA = cos(angle);
        float x = cosA * radius[fIdx];
        float y = sinA * radius[fIdx];

        position[index3j] = position[index3i] + x;
        position[index3j+1] = position[index3i+1] + y;
        position[index3j+2] = 0.0f;

        // travel scaled unit length
        velocity[index3j] = cosA/5.0;
        velocity[index3j+1] = sinA/5.0;
        velocity[index3j+2] = 0.0f;
    }
}

__global__ void kernelAdvanceHypnosis() {
    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;

    float* radius = cuConstRendererParams.radius;

    float cutOff = 0.5f;
    // place circle back in center after reaching threshold radisus
    if (radius[index] > cutOff) {
        radius[index] = 0.02f;
    } else {
        radius[index] += 0.01f;
    }
}


__global__ void kernelAdvanceBouncingBalls() {
    const float dt = 1.f / 60.f;
    const float kGravity = -2.8f; // sorry Newton
    const float kDragCoeff = -0.8f;
    const float epsilon = 0.001f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;

    int index3 = 3 * index;
    // reverse velocity if center position < 0
    float oldVelocity = velocity[index3+1];
    float oldPosition = position[index3+1];

    if (oldVelocity == 0.f && oldPosition == 0.f) { // stop-condition
        return;
    }

    if (position[index3+1] < 0 && oldVelocity < 0.f) { // bounce ball
        velocity[index3+1] *= kDragCoeff;
    }

    // update velocity: v = u + at (only along y-axis)
    velocity[index3+1] += kGravity * dt;

    // update positions (only along y-axis)
    position[index3+1] += velocity[index3+1] * dt;

    if (fabsf(velocity[index3+1] - oldVelocity) < epsilon
        && oldPosition < 0.0f
        && fabsf(position[index3+1]-oldPosition) < epsilon) { // stop ball
        velocity[index3+1] = 0.f;
        position[index3+1] = 0.f;
    }
}

__global__ void kernelAdvanceSnowflake() {
    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    const float dt = 1.f / 60.f;
    const float kGravity = -1.8f; // sorry Newton
    const float kDragCoeff = 2.f;

    int index3 = 3 * index;

    float* positionPtr = &cuConstRendererParams.position[index3];
    float* velocityPtr = &cuConstRendererParams.velocity[index3];

    // loads from global memory
    float3 position = *((float3*)positionPtr);
    float3 velocity = *((float3*)velocityPtr);

    // hack to make farther circles move more slowly, giving the
    // illusion of parallax
    float forceScaling = fmin(fmax(1.f - position.z, .1f), 1.f); // clamp

    // add some noise to the motion to make the snow flutter
    float3 noiseInput;
    noiseInput.x = 10.f * position.x;
    noiseInput.y = 10.f * position.y;
    noiseInput.z = 255.f * position.z;
    float2 noiseForce = cudaVec2CellNoise(noiseInput, index);
    noiseForce.x *= 7.5f;
    noiseForce.y *= 5.f;

    // drag
    float2 dragForce;
    dragForce.x = -1.f * kDragCoeff * velocity.x;
    dragForce.y = -1.f * kDragCoeff * velocity.y;

    // update positions
    position.x += velocity.x * dt;
    position.y += velocity.y * dt;

    // update velocities
    velocity.x += forceScaling * (noiseForce.x + dragForce.y) * dt;
    velocity.y += forceScaling * (kGravity + noiseForce.y + dragForce.y) * dt;

    float radius = cuConstRendererParams.radius[index];

    // if the snowflake has moved off the left, right or bottom of
    // the screen, place it back at the top and give it a
    // pseudorandom x position and velocity.
    if ( (position.y + radius < 0.f) ||
         (position.x + radius) < -0.f ||
         (position.x - radius) > 1.f)
    {
        noiseInput.x = 255.f * position.x;
        noiseInput.y = 255.f * position.y;
        noiseInput.z = 255.f * position.z;
        noiseForce = cudaVec2CellNoise(noiseInput, index);

        position.x = .5f + .5f * noiseForce.x;
        position.y = 1.35f + radius;

        // restart from 0 vertical velocity.  Choose a
        // pseudo-random horizontal velocity.
        velocity.x = 2.f * noiseForce.y;
        velocity.y = 0.f;
    }

    // store updated positions and velocities to global memory
    *((float3*)positionPtr) = position;
    *((float3*)velocityPtr) = velocity;
}


// --- KERNELS: Preprocessing Step 1: Count Intersections per Tile ---
__global__ void kernelCountTileIntersections(unsigned int* d_tileCounts) {
    int circleIndex = blockIdx.x * blockDim.x + threadIdx.x;
    if (circleIndex >= cuConstRendererParams.numCircles) {
        return;
    }

    // Load circle data
    int index3 = 3 * circleIndex;
    float circleX = cuConstRendererParams.position[index3];
    float circleY = cuConstRendererParams.position[index3+1];
    float circleRad = cuConstRendererParams.radius[circleIndex];

    // Determine range of tiles this circle *might* overlap
    // Calculate bounds of circle in pixel coordinates
    float circleL_px = (circleX - circleRad) * cuConstRendererParams.imageWidth;
    float circleR_px = (circleX + circleRad) * cuConstRendererParams.imageWidth;
    float circleB_px = (circleY - circleRad) * cuConstRendererParams.imageHeight;
    float circleT_px = (circleY + circleRad) * cuConstRendererParams.imageHeight;

    // Convert pixel bounds to tile index bounds
    int startTileX = max(0, static_cast<int>(floorf(circleL_px / cuConstRendererParams.tileDimX)));
    int endTileX   = min(cuConstRendererParams.numTilesX - 1, static_cast<int>(floorf(circleR_px / cuConstRendererParams.tileDimX)));
    int startTileY = max(0, static_cast<int>(floorf(circleB_px / cuConstRendererParams.tileDimY)));
    int endTileY   = min(cuConstRendererParams.numTilesY - 1, static_cast<int>(floorf(circleT_px / cuConstRendererParams.tileDimY)));

    // Iterate through potentially overlapping tiles
    for (int ty = startTileY; ty <= endTileY; ++ty) {
        for (int tx = startTileX; tx <= endTileX; ++tx) {
            // Calculate tile boundaries in normalized coordinates
            float tileL = cuConstRendererParams.invWidth * static_cast<float>(tx * cuConstRendererParams.tileDimX);
            float tileR = cuConstRendererParams.invWidth * static_cast<float>((tx + 1) * cuConstRendererParams.tileDimX);
            float tileB = cuConstRendererParams.invHeight * static_cast<float>(ty * cuConstRendererParams.tileDimY);
            float tileT = cuConstRendererParams.invHeight * static_cast<float>((ty + 1) * cuConstRendererParams.tileDimY);

            // Conservative check
            if (circleInBoxConservative(circleX, circleY, circleRad, tileL, tileR, tileT, tileB)) {
                int tileId = ty * cuConstRendererParams.numTilesX + tx;
                atomicAdd(&d_tileCounts[tileId], 1);
            }
        }
    }
}

// --- KERNELS: Preprocessing Step 2: Generate (circleIdx, tileId) pairs ---
// Note: d_tileCounts is reused here as the atomic write cursor per tile,
// it should be pre-loaded with the exclusive scan result (offsets) before launch.
__global__ void kernelGeneratePairs() {
    int circleIndex = blockIdx.x * blockDim.x + threadIdx.x;
    if (circleIndex >= cuConstRendererParams.numCircles) {
        return;
    }

    // Load circle data
    int index3 = 3 * circleIndex;
    float circleX = cuConstRendererParams.position[index3];
    float circleY = cuConstRendererParams.position[index3+1];
    float circleRad = cuConstRendererParams.radius[circleIndex];

    // Determine range of tiles this circle *might* overlap (same logic as kernelCountTileIntersections)
    float circleL_px = (circleX - circleRad) * cuConstRendererParams.imageWidth;
    float circleR_px = (circleX + circleRad) * cuConstRendererParams.imageWidth;
    float circleB_px = (circleY - circleRad) * cuConstRendererParams.imageHeight;
    float circleT_px = (circleY + circleRad) * cuConstRendererParams.imageHeight;

    int startTileX = max(0, static_cast<int>(floorf(circleL_px / cuConstRendererParams.tileDimX)));
    int endTileX   = min(cuConstRendererParams.numTilesX - 1, static_cast<int>(floorf(circleR_px / cuConstRendererParams.tileDimX)));
    int startTileY = max(0, static_cast<int>(floorf(circleB_px / cuConstRendererParams.tileDimY)));
    int endTileY   = min(cuConstRendererParams.numTilesY - 1, static_cast<int>(floorf(circleT_px / cuConstRendererParams.tileDimY)));

    // Iterate through potentially overlapping tiles
    for (int ty = startTileY; ty <= endTileY; ++ty) {
        for (int tx = startTileX; tx <= endTileX; ++tx) {
            // Calculate tile boundaries
            float tileL = cuConstRendererParams.invWidth * static_cast<float>(tx * cuConstRendererParams.tileDimX);
            float tileR = cuConstRendererParams.invWidth * static_cast<float>((tx + 1) * cuConstRendererParams.tileDimX);
            float tileB = cuConstRendererParams.invHeight * static_cast<float>(ty * cuConstRendererParams.tileDimY);
            float tileT = cuConstRendererParams.invHeight * static_cast<float>((ty + 1) * cuConstRendererParams.tileDimY);

            // Conservative check
            if (circleInBoxConservative(circleX, circleY, circleRad, tileL, tileR, tileT, tileB)) {
                int tileId = ty * cuConstRendererParams.numTilesX + tx;
                // Atomically get the write index for this tile's list segment
                // d_tileCounts here holds the *offsets* plus increments
                unsigned int writeIndex = atomicAdd(&cuConstRendererParams.d_tileCounts[tileId], 1);

                // Write the pair (using the pointers passed via constant memory)
                cuConstRendererParams.d_circleTilePairIndices[writeIndex] = circleIndex;
                cuConstRendererParams.d_circleTilePairTiles[writeIndex] = tileId;
            }
        }
    }
}


// --- KERNEL: Main Rendering Kernel (using precomputed lists) ---
__global__ void kernelRenderTilesFromLists(const unsigned int* d_tileListOffsets,
                                           const int* d_tileCircleLists) // Read-only list of circle indices
{
    // Calculate this thread's pixel coordinates (global image coordinates)
    int tileX = blockIdx.x;
    int tileY = blockIdx.y;
    int threadX = threadIdx.x;
    int threadY = threadIdx.y;

    int globalPixelX = tileX * TILE_DIM_X + threadX;
    int globalPixelY = tileY * TILE_DIM_Y + threadY;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if pixel is outside image bounds
    if (globalPixelX >= imageWidth || globalPixelY >= imageHeight) {
        return;
    }

    // Calculate normalized pixel center coordinates [0, 1]
    float pixelCenterX = cuConstRendererParams.invWidth * (static_cast<float>(globalPixelX) + 0.5f);
    float pixelCenterY = cuConstRendererParams.invHeight * (static_cast<float>(globalPixelY) + 0.5f);
    float2 pixelCenterNorm = make_float2(pixelCenterX, pixelCenterY);

    // Get the tile ID
    int tileId = tileY * cuConstRendererParams.numTilesX + tileX;

    // Find the range of circle indices for this tile in the global list
    unsigned int startOffset = d_tileListOffsets[tileId];
    unsigned int endOffset = d_tileListOffsets[tileId + 1]; // Offset list includes total count at the end

    // Initialize accumulated color by reading the background color for this pixel
    int pixelOffset = 4 * (globalPixelY * imageWidth + globalPixelX);
    float4 accumulatedColor = *(float4*)(&cuConstRendererParams.imageData[pixelOffset]);

    // Iterate ONLY through the circles relevant to this tile
    for (unsigned int i = startOffset; i < endOffset; ++i) {
        int circleIndex = d_tileCircleLists[i]; // Get the original circle index

        // Read circle data directly from global memory using circleIndex
        int index3_pos_vel = 3 * circleIndex;
        float circleX = cuConstRendererParams.position[index3_pos_vel];
        float circleY = cuConstRendererParams.position[index3_pos_vel + 1];
        float circleZ = cuConstRendererParams.position[index3_pos_vel + 2]; // Needed for snow
        float circleRad = cuConstRendererParams.radius[circleIndex];

        // --- Per-Pixel Test ---
        // Check if the pixel center is inside this circle
        float diffX = circleX - pixelCenterNorm.x;
        float diffY = circleY - pixelCenterNorm.y;
        float distSq = diffX * diffX + diffY * diffY;
        float radSq = circleRad * circleRad;

        if (distSq <= radSq) {
            // Pixel center is inside the circle, calculate color contribution and blend

            float3 circleRgb;
            float circleAlpha;

            // Determine circle color and alpha based on scene type
            if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
                const float kCircleMaxAlpha = .5f;
                const float falloffScale = 4.f;

                float normPixelDist = sqrtf(distSq) / circleRad;
                circleRgb = lookupColor(normPixelDist); // Uses lookupColor.cu_inl

                float maxAlpha = .6f + .4f * (1.f - circleZ); // Use circle's Z for alpha modulation
                maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f); // Clamp and scale
                circleAlpha = maxAlpha * expf(-1.f * falloffScale * normPixelDist * normPixelDist);
            } else {
                // Simple case: fixed color per circle, fixed alpha
                int index3_color = 3 * circleIndex;
                circleRgb = *(float3*)&(cuConstRendererParams.color[index3_color]);
                circleAlpha = .5f; // Default alpha for non-snowflake scenes
            }

            // Perform the blending operation using the "over" operator into the accumulator
            float oneMinusAlpha = 1.f - circleAlpha;
            accumulatedColor.x = circleAlpha * circleRgb.x + oneMinusAlpha * accumulatedColor.x;
            accumulatedColor.y = circleAlpha * circleRgb.y + oneMinusAlpha * accumulatedColor.y;
            accumulatedColor.z = circleAlpha * circleRgb.z + oneMinusAlpha * accumulatedColor.z;
            // Keep framebuffer opaque - matches clear behavior and reference impl intent
            accumulatedColor.w = 1.f;

        } // End if pixel in circle
    } // End loop through relevant circles for this tile

    // After processing all relevant circles, write the final accumulated color to global memory
    *(float4*)(&cuConstRendererParams.imageData[pixelOffset]) = accumulatedColor;
}

    // Pass pointers to the *read-only* offset and circle list buffers

    cudaCheckError(cudaDeviceSynchronize());

Optimized CUDA Renderer Strategy

Optimized CUDA Circle Renderer

Based on the performance analysis of the previous tile-centric approach, the primary bottleneck was that every tile (CUDA block) still had to iterate through all circles (or chunks of circles), even if only a few circles actually overlapped the tile. This leads to significant redundant computation and poor load balancing, especially in sparse scenes or scenes with varying density (like `biglittle`). The execution times, particularly for `rand10k` through `micro2M`, were significantly higher than the reference, indicating substantial inefficiency. The new strategy aims to drastically reduce the work per tile by pre-calculating exactly which circles overlap which tiles, ensuring that the rendering kernel only processes relevant circles for each tile.

strategy:

  1. Preprocessing - Circle Binning/Sorting: Before rendering, perform a preprocessing step to determine which circles potentially overlap which image tiles.
    • Launch a kernel (`kernelGeneratePairCounts`) where each thread processes one circle to count how many tiles it precisely overlaps using the `circleInBox` test.
    • Perform an exclusive scan (using `thrust::exclusive_scan`) on these counts to determine the total number of circle-tile overlaps (`total_pairs`) and the starting write offset for each circle in a temporary global buffer.
    • Allocate temporary global memory buffers (`d_temp_pair_keys` for `tile_idx`, `d_temp_pair_values` for `circle_idx`) sized to `total_pairs`. Handle potential allocation failures, especially for large scenes.
    • Launch a second kernel (`kernelWriteCircleTilePairs`) where each thread processes one circle again. It recalculates the overlapping tiles using `circleInBox` and writes the `(tile_idx, circle_idx)` pairs to the temporary buffers using the offsets calculated in the previous step.
    • Use `thrust::sort_by_key` to sort the temporary pairs primarily by `tile_idx` and secondarily by `circle_idx`. The sorted `circle_idx` values now form the global list of relevant circles per tile (`d_tile_circle_indices`). The sorted `tile_idx` keys are stored in `d_temp_pair_keys`.
  2. Preprocessing - Tile Offset Calculation:
    • Use `thrust::reduce_by_key` on the sorted `tile_idx` keys (`d_temp_pair_keys`) to find the unique tile indices that have overlapping circles and the count of circles for each unique tile.
    • Copy the unique tile indices (`h_unique_tile_keys`) and their counts (`h_counts_for_unique_tiles`) back to the host.
    • On the host, compute the exclusive scan of the unique tile counts (`h_offsets_for_unique_tiles`).
    • On the host, construct the final `d_tile_offsets` array (size `num_tiles + 1`). Initialize it appropriately (e.g., with -1, setting `h_tile_offsets[0] = 0`). Iterate through the unique tiles, using `h_unique_tile_keys` to index into `h_tile_offsets` and store the corresponding `h_offsets_for_unique_tiles`.
    • Perform a pass on the host `h_tile_offsets` array to fill in gaps: if `h_tile_offsets[i]` is still -1, copy the value from `h_tile_offsets[i-1]`.
    • Set the last element `h_tile_offsets[num_tiles]` to `total_pairs`.
    • Copy the completed `d_tile_offsets` array from the host (`h_tile_offsets`) to the device (`d_tile_offsets`).
  3. Rendering Kernel (`kernelRenderTilesBinned`):
    • Launch a 2D grid of thread blocks, where each block corresponds to one tile (`TILE_DIM_X` x `TILE_DIM_Y` threads per block, e.g., 16x16).
    • Each block uses its `blockIdx` to determine its `tile_idx`.
    • Using the `d_tile_offsets` array (persistent device memory), the block determines the start (`offset_start = d_tile_offsets[tile_idx]`) and end (`offset_end = d_tile_offsets[tile_idx + 1]`) indices for its list of relevant circles within the globally sorted `d_tile_circle_indices` array (which points to the sorted `d_temp_pair_values` buffer).
    • Each thread within the block calculates the coordinates (`globalPixelX`, `globalPixelY`) and normalized center (`pixelCenterNorm`) of the pixel it is responsible for.
    • Each thread initializes a local color accumulator variable (e.g., in registers) by reading the initial background color from the global image buffer (`imageData`) for its assigned pixel. Bounds checks ensure reads/writes only happen for pixels within the image.
    • All threads in the block iterate through the relevant circle indices for this tile (looping from `offset_start` to `offset_end`).
    • For each `list_idx` in the loop range:
      • Get the original `circle_idx = d_tile_circle_indices[list_idx]`.
      • The thread reads the circle's position (`circleX`, `circleY`, `circleZ`) and `circleRad` from global memory using `circle_idx`.
      • It performs the per-pixel distance check (`distSq <= radSq`) to see if its pixel center is covered by this circle.
      • If covered:
        • The thread reads the circle's color (`circleRgb`) from global memory (or computes it for snowflake scenes using `lookupColor` and `circleZ`).
        • It calculates the `circleAlpha` (fixed 0.5f or computed based on distance/Z for snow).
        • The thread blends the circle's contribution into its local `accumulatedColor` register variable using the standard "over" operator math.
    • After iterating through all relevant circles for the tile, each thread writes its final `accumulatedColor` back to the correct location (`pixelOffset`) in the global image buffer (`imageData`), again guarded by the image bounds check.

reasoning:

  • Addressing Bottleneck: The core idea is to eliminate the need for every tile/block to check every circle. By pre-calculating and sorting a list of relevant circles (`d_tile_circle_indices`) for each tile, the rendering kernel (`kernelRenderTilesBinned`) only performs work (intersection tests, blending) for circles that actually overlap its assigned tile. This directly addresses the major performance limitation of the previous approach, which caused extremely high runtimes on tests with many circles.
  • Work Distribution & Load Balancing: While static tile-to-block assignment remains, the amount of work *within* each block is now proportional to the number of circles actually overlapping that tile. Blocks assigned to empty or sparse tiles execute the rendering kernel loop zero or few times, while blocks in dense areas process only the relevant circles. This leads to much better overall workload distribution and avoids wasting computation compared to iterating through all circles everywhere.
  • Memory Access:
    • The preprocessing step involves potentially scattered reads/writes during pair generation and significant bandwidth during sorting (`thrust::sort_by_key`) and reduction (`thrust::reduce_by_key`). Thrust operations are highly optimized for these patterns on the GPU. The temporary buffer for pairs can be large, requiring careful allocation.
    • The rendering kernel reads `d_tile_circle_indices` sequentially for each tile's list. Accesses to circle data (position, radius, color) are indirect via `circle_idx` fetched from the list. While these accesses might be somewhat scattered globally, they are likely to benefit from L1/L2 caching, especially since threads within a block process the same list of circles. Crucially, it avoids reading data for the vast majority of circles that are irrelevant to the current tile.
    • The strategy explicitly avoids using shared memory in the rendering kernel for caching circle data to maintain simplicity. The performance gain comes primarily from reducing the number of circles processed per tile, rather than optimizing the access to those circles via shared memory.
    • Constructing the final `d_tile_offsets` array on the host after copying back the small unique key/count data is efficient as the data transfer size is minimal (typically #tiles * 8 bytes), and avoids complex parallel prefix/fill logic on the GPU for this step.
  • Correctness Preservation:
    • Order: The `thrust::sort_by_key` step sorts first by `tile_idx` and uses `circle_idx` as the secondary sorting key. This is crucial: it ensures that within the sub-list for any given tile in `d_tile_circle_indices`, circles appear in their original input order (0, 1, 2...). The rendering kernel processes this list sequentially (`for list_idx = offset_start to offset_end`), thus performing the blending operations for any given pixel in the correct, original circle order, satisfying the requirement.
    • Atomicity: Each pixel's final color is computed entirely within a single thread's local accumulator variable (registers). The thread reads the initial background color, performs all blending operations locally, and then performs a single write of the final color to the global image buffer at the end. This avoids read-modify-write hazards and ensures atomicity without requiring atomic operations or locks in the rendering kernel's main loop.
  • Scalability: This approach is expected to scale much better with the number of circles (`numCircles`) than the previous tile-centric approach. The preprocessing cost (binning, sorting, reducing) scales roughly with the number of circle-tile overlaps (approximately O(P log P) for sorting, where P is total pairs, often proportional to N), which is generally much better than the previous O(NumTiles * NumCircles) complexity. The rendering cost per tile becomes dependent only on the *local* circle density within that tile, not the global circle count. This should yield significant speedups for scenes like `rand100k`, `rand1M`, and `micro2M`.
  • Feasibility & Tools: The strategy leverages the powerful Thrust library for parallel sorting, scanning, and reduction, simplifying the implementation of the complex preprocessing steps. The temporary memory required for storing circle-tile pairs, while potentially large (estimated ~64MB for `micro2M`), is generally manageable on modern GPUs and significantly less than what a full fragment-based approach might require. Error checking on memory allocations is important.

__global__ void kernelClearImageSnowflake(int width, int height, float* imageData) {
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    if (imageX >= width || imageY >= height) return;

    int offset = 4 * (imageY * width + imageX);
    float shade = .4f + .45f * static_cast<float>(height-imageY) / height;
    float4 value = make_float4(shade, shade, shade, 1.f);
    *(float4*)(&imageData[offset]) = value;
}

__global__ void kernelClearImage(float r, float g, float b, float a, int width, int height, float* imageData) {
    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    if (imageX >= width || imageY >= height) return;

    int offset = 4 * (imageY * width + imageX);
    float4 value = make_float4(r, g, b, a);
    *(float4*)(&imageData[offset]) = value;
}

__global__ void kernelAdvanceFireWorks(int numCircles, float* position, float* velocity, float* radius) {
    const float dt = 1.f / 60.f;
    const float pi = 3.14159;
    const float maxDist = 0.25f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= numCircles)
        return;
    if (0 <= index && index < NUM_FIREWORKS) { // firework center; no update
        return;
    }
    int fIdx = (index - NUM_FIREWORKS) / NUM_SPARKS;
    int sfIdx = (index - NUM_FIREWORKS) % NUM_SPARKS;

    int index3i = 3 * fIdx;
    int sIdx = NUM_FIREWORKS + fIdx * NUM_SPARKS + sfIdx;
    int index3j = 3 * sIdx;
    float cx = position[index3i];
    float cy = position[index3i+1];

    // update position
    position[index3j] += velocity[index3j] * dt;
    position[index3j+1] += velocity[index3j+1] * dt;

    float sx = position[index3j];
    float sy = position[index3j+1];
    float cxsx = sx - cx;
    float cysy = sy - cy;
    float dist = sqrt(cxsx * cxsx + cysy * cysy);

    if (dist > maxDist) { // restore to starting position
        float angle = (sfIdx * 2 * pi)/NUM_SPARKS;
        float sinA = sin(angle);
        float cosA = cos(angle);
        float x = cosA * radius[fIdx];
        float y = sinA * radius[fIdx];

        position[index3j] = position[index3i] + x;
        position[index3j+1] = position[index3i+1] + y;
        position[index3j+2] = 0.0f;
        velocity[index3j] = cosA/5.0;
        velocity[index3j+1] = sinA/5.0;
        velocity[index3j+2] = 0.0f;
    }
}

__global__ void kernelAdvanceHypnosis(int numCircles, float* radius) {
    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= numCircles)
        return;
    float cutOff = 0.5f;
    if (radius[index] > cutOff) {
        radius[index] = 0.02f;
    } else {
        radius[index] += 0.01f;
    }
}

__global__ void kernelAdvanceBouncingBalls(int numCircles, float* position, float* velocity) {
    const float dt = 1.f / 60.f;
    const float kGravity = -2.8f;
    const float kDragCoeff = -0.8f;
    const float epsilon = 0.001f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= numCircles) return;

    int index3 = 3 * index;
    float oldVelocity = velocity[index3+1];
    float oldPosition = position[index3+1];

    if (oldVelocity == 0.f && oldPosition == 0.f) return;

    if (position[index3+1] < 0 && oldVelocity < 0.f) { // bounce ball
        velocity[index3+1] *= kDragCoeff;
    }
    velocity[index3+1] += kGravity * dt; // update velocity
    position[index3+1] += velocity[index3+1] * dt; // update position

    if (fabsf(velocity[index3+1] - oldVelocity) < epsilon
        && oldPosition < 0.0f
        && fabsf(position[index3+1]-oldPosition) < epsilon) { // stop ball
        velocity[index3+1] = 0.f;
        position[index3+1] = 0.f;
    }
}

__global__ void kernelAdvanceSnowflake(int numCircles, float* position, float* velocity, float* radius) {
     int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= numCircles) return;

    const float dt = 1.f / 60.f;
    const float kGravity = -1.8f;
    const float kDragCoeff = 2.f;
    int index3 = 3 * index;

    float* positionPtr = &position[index3];
    float* velocityPtr = &velocity[index3];
    float3 pos = *((float3*)positionPtr);
    float3 vel = *((float3*)velocityPtr);
    float rad = radius[index];

    float forceScaling = fmin(fmax(1.f - pos.z, .1f), 1.f); // parallax

    // Noise/Flutter
    float3 noiseInput = make_float3(10.f * pos.x, 10.f * pos.y, 255.f * pos.z);
    float2 noiseForce = cudaVec2CellNoise(noiseInput, index);
    noiseForce.x *= 7.5f; noiseForce.y *= 5.f;

    // Drag
    float2 dragForce = make_float2(-1.f * kDragCoeff * vel.x, -1.f * kDragCoeff * vel.y);

    // Update position/velocity
    pos.x += vel.x * dt;
    pos.y += vel.y * dt;
    vel.x += forceScaling * (noiseForce.x + dragForce.x) * dt; // Corrected: drag.x not drag.y
    vel.y += forceScaling * (kGravity + noiseForce.y + dragForce.y) * dt;


    // Screen boundary check and reset
    if ( (pos.y + rad < 0.f) || (pos.x + rad) < -0.f || (pos.x - rad) > 1.f) {
        noiseInput = make_float3(255.f * pos.x, 255.f * pos.y, 255.f * pos.z);
        noiseForce = cudaVec2CellNoise(noiseInput, index);
        pos.x = .5f + .5f * noiseForce.x;
        pos.y = 1.35f + rad; // Place back above screen
        vel.x = 2.f * noiseForce.y;
        vel.y = 0.f;
    }

    // Store updated values
    *((float3*)positionPtr) = pos;
    *((float3*)velocityPtr) = vel;
}

// Kernel 1: Count overlapping tiles per circle
__global__ void kernelGeneratePairCounts(
    int numCircles,
    const float* __restrict__ position, // float3
    const float* __restrict__ radius,
    int imageWidth, int imageHeight,
    int numTilesX, int numTilesY,
    int* d_pair_counts_per_circle) // Output: count per circle
{
    int circle_idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (circle_idx >= numCircles) return;

    // Precompute inverses
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float tileWidthNorm = static_cast<float>(TILE_DIM_X) * invWidth;
    float tileHeightNorm = static_cast<float>(TILE_DIM_Y) * invHeight;

    int index3 = 3 * circle_idx;
    float circleX = position[index3];
    float circleY = position[index3+1];
    float circleR = radius[circle_idx];

    // Calculate circle bounding box in normalized coords [0, 1]
    float circleL = circleX - circleR;
    float circleR_ = circleX + circleR;
    float circleB = circleY - circleR;
    float circleT = circleY + circleR;

    // Calculate tile index range (more precise using floor)
    // Clamp to valid tile range [0, numTilesX/Y - 1]
    int minTileX = max(0, static_cast<int>(floorf(circleL / tileWidthNorm)));
    int maxTileX = min(numTilesX - 1, static_cast<int>(floorf(circleR_ / tileWidthNorm)));
    int minTileY = max(0, static_cast<int>(floorf(circleB / tileHeightNorm)));
    int maxTileY = min(numTilesY - 1, static_cast<int>(floorf(circleT / tileHeightNorm)));

    int overlap_count = 0;
    for (int ty = minTileY; ty <= maxTileY; ++ty) {
        for (int tx = minTileX; tx <= maxTileX; ++tx) {
            // Calculate exact tile boundaries in normalized coordinates
            float tileL = static_cast<float>(tx) * tileWidthNorm;
            float tileR = tileL + tileWidthNorm; // Avoid recomputing tx+1
            float tileB = static_cast<float>(ty) * tileHeightNorm;
            float tileT = tileB + tileHeightNorm; // Avoid recomputing ty+1

            // Precise check if circle intersects this tile
            if (circleInBox(circleX, circleY, circleR, tileL, tileR, tileT, tileB)) {
                overlap_count++;
            }
        }
    }
    d_pair_counts_per_circle[circle_idx] = overlap_count;
}


// Kernel 2: Write (tile_idx, circle_idx) pairs to temporary buffers
__global__ void kernelWriteCircleTilePairs(
    int numCircles,
    const float* __restrict__ position, // float3
    const float* __restrict__ radius,
    int imageWidth, int imageHeight,
    int numTilesX, int numTilesY,
    const int* __restrict__ d_pair_write_offsets, // Input: scan results
    int* d_temp_pair_keys,   // Output: tile_idx
    int* d_temp_pair_values) // Output: circle_idx
{
    int circle_idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (circle_idx >= numCircles) return;

    // Precompute inverses
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float tileWidthNorm = static_cast<float>(TILE_DIM_X) * invWidth;
    float tileHeightNorm = static_cast<float>(TILE_DIM_Y) * invHeight;

    int index3 = 3 * circle_idx;
    float circleX = position[index3];
    float circleY = position[index3+1];
    float circleR = radius[circle_idx];

    // Calculate circle bounding box in normalized coords [0, 1]
    float circleL = circleX - circleR;
    float circleR_ = circleX + circleR;
    float circleB = circleY - circleR;
    float circleT = circleY + circleR;

    // Calculate tile index range (more precise using floor)
    int minTileX = max(0, static_cast<int>(floorf(circleL / tileWidthNorm)));
    int maxTileX = min(numTilesX - 1, static_cast<int>(floorf(circleR_ / tileWidthNorm)));
    int minTileY = max(0, static_cast<int>(floorf(circleB / tileHeightNorm)));
    int maxTileY = min(numTilesY - 1, static_cast<int>(floorf(circleT / tileHeightNorm)));

    int write_offset = d_pair_write_offsets[circle_idx];
    int current_pair_index = 0;

    for (int ty = minTileY; ty <= maxTileY; ++ty) {
        for (int tx = minTileX; tx <= maxTileX; ++tx) {
            // Calculate tile boundaries
            float tileL = static_cast<float>(tx) * tileWidthNorm;
            float tileR = tileL + tileWidthNorm;
            float tileB = static_cast<float>(ty) * tileHeightNorm;
            float tileT = tileB + tileHeightNorm;

            // Precise check if circle intersects this tile
            if (circleInBox(circleX, circleY, circleR, tileL, tileR, tileT, tileB)) {
                int tile_idx = ty * numTilesX + tx;
                int write_pos = write_offset + current_pair_index;
                // Check bounds before writing (important if total_pairs was estimated/incorrect)
                // This check should ideally not be needed if total_pairs is exact from scan
                // if (write_pos < total_pairs_capacity) {
                    d_temp_pair_keys[write_pos] = tile_idx;
                    d_temp_pair_values[write_pos] = circle_idx;
                // }
                current_pair_index++;
            }
        }
    }
}


//////////////////////////////////////////////////////////////////
// Optimized Rendering Kernel (using binned lists)
//////////////////////////////////////////////////////////////////
__global__ void kernelRenderTilesBinned(
    int imageWidth, int imageHeight, float* imageData, // Output image
    int numTilesX, int numTilesY, // Tile grid dimensions
    const int* __restrict__ d_tile_offsets,        // Input: offsets for each tile
    const int* __restrict__ d_tile_circle_indices, // Input: sorted circle indices
    SceneName sceneName,                           // Input: needed for shading logic
    int numCircles,                                // Input: needed for color lookup bounds
    const float* __restrict__ position,            // Input: circle pos (float3)
    const float* __restrict__ color,               // Input: circle color (float3)
    const float* __restrict__ radius)              // Input: circle radius (float)
{
    // Determine tile coordinates from block index
    int tileX = blockIdx.x;
    int tileY = blockIdx.y;
    int tile_idx = tileY * numTilesX + tileX;

    // Determine thread coordinates within the block
    int threadX = threadIdx.x;
    int threadY = threadIdx.y;

    // Calculate global pixel coordinates this thread is responsible for
    int globalPixelX = tileX * TILE_DIM_X + threadX;
    int globalPixelY = tileY * TILE_DIM_Y + threadY;

    // Check if pixel is within image bounds before doing any work
    if (globalPixelX >= imageWidth || globalPixelY >= imageHeight) {
        return;
    }

    // Calculate normalized pixel center coordinates [0, 1]
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float pixelCenterX = invWidth * (static_cast<float>(globalPixelX) + 0.5f);
    float pixelCenterY = invHeight * (static_cast<float>(globalPixelY) + 0.5f);
    float2 pixelCenterNorm = make_float2(pixelCenterX, pixelCenterY);

    // Calculate the memory offset for this pixel
    int pixelOffset = 4 * (globalPixelY * imageWidth + globalPixelX);

    // Initialize local accumulator with background color from global memory
    // IMPORTANT: Assumes clearImage has already run and filled imageData
    float4 accumulatedColor = *(float4*)(&imageData[pixelOffset]);

    // Get the start and end offsets for this tile's circle list
    // Note: d_tile_offsets has size num_tiles + 1
    int offset_start = d_tile_offsets[tile_idx];
    int offset_end = d_tile_offsets[tile_idx + 1];

    // Iterate through the relevant circles for this tile
    for (int list_idx = offset_start; list_idx < offset_end; ++list_idx) {
        // Get the original circle index from the sorted list
        int circle_idx = d_tile_circle_indices[list_idx];

        // --- Load Circle Data (Position/Radius) ---
        int index3_pos = 3 * circle_idx;
        // Bounds check for safety (although indices should be valid)
        if (index3_pos + 2 >= 3 * numCircles || circle_idx >= numCircles) continue;

        float circleX = position[index3_pos];
        float circleY = position[index3_pos + 1];
        float circleZ = position[index3_pos + 2]; // Needed for snow alpha/color
        float circleRad = radius[circle_idx];

        // --- Per-Pixel Test ---
        float diffX = circleX - pixelCenterNorm.x;
        float diffY = circleY - pixelCenterNorm.y;
        float distSq = diffX * diffX + diffY * diffY;
        float radSq = circleRad * circleRad;

        if (distSq <= radSq) {
            // Pixel center is inside the circle, calculate color contribution and blend
            float3 circleRgb;
            float circleAlpha;

            // Determine circle color and alpha based on scene type
            if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
                const float kCircleMaxAlpha = .5f;
                const float falloffScale = 4.f;
                // Avoid sqrt if possible, use distSq. If sqrt needed, check radius > 0.
                float normPixelDist = 0.f;
                if (circleRad > 1e-6f) { // Avoid division by zero / sqrt(0)
                     normPixelDist = sqrtf(distSq) / circleRad;
                }
                circleRgb = lookupColor(normPixelDist); // Uses lookupColor.cu_inl

                float maxAlpha = .6f + .4f * (1.f - circleZ); // Use circle's Z for alpha modulation
                maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f); // Clamp and scale
                circleAlpha = maxAlpha * expf(-1.f * falloffScale * normPixelDist * normPixelDist);
            } else {
                // Simple case: fixed color per circle, fixed alpha
                int index3_color = 3 * circle_idx;
                 // Check bounds for safety
                if (index3_color + 2 < 3 * numCircles) {
                     circleRgb = *(float3*)&(color[index3_color]);
                } else {
                    // Handle potential error or default color
                     circleRgb = make_float3(1.f, 0.f, 1.f); // Magenta for error
                }
                circleAlpha = .5f; // Default alpha for non-snowflake scenes
            }

            // Perform the blending operation using the "over" operator into the accumulator
            // Ensure alpha is clamped [0, 1] for stability
            circleAlpha = fmaxf(0.f, fminf(1.f, circleAlpha));
            float oneMinusAlpha = 1.f - circleAlpha;
            accumulatedColor.x = circleAlpha * circleRgb.x + oneMinusAlpha * accumulatedColor.x;
            accumulatedColor.y = circleAlpha * circleRgb.y + oneMinusAlpha * accumulatedColor.y;
            accumulatedColor.z = circleAlpha * circleRgb.z + oneMinusAlpha * accumulatedColor.z;
            // Framebuffer alpha remains opaque (consistent with reference behavior)
            accumulatedColor.w = 1.f;

        } // End if pixel in circle
    } // End loop through relevant circles for this tile

    // After processing all relevant circles, write the final accumulated color to global memory
    *(float4*)(&imageData[pixelOffset]) = accumulatedColor;
}

CudaRenderer::CudaRenderer() :
    image(NULL),
    numCircles(0),
    position(NULL), velocity(NULL), color(NULL), radius(NULL), // Host copies
    cudaDevicePosition(NULL), cudaDeviceVelocity(NULL), cudaDeviceColor(NULL), cudaDeviceRadius(NULL), cudaDeviceImageData(NULL), // Device basic data
    d_tile_offsets(NULL), // Device offsets per tile
    d_tile_circle_indices_ptr(NULL), // Raw pointer to sorted indices (managed by Thrust vec)
    numTilesX(0), numTilesY(0), total_pairs(0)
{}

CudaRenderer::~CudaRenderer() {
    if (image) {
        delete image;
    }
    // Free host memory
    if (position) { delete [] position; }
    if (velocity) { delete [] velocity; }
    if (color)    { delete [] color;    }
    if (radius)   { delete [] radius;   }

    // Free CUDA memory using cudaFree (safe to call on NULL)
    cudaFree(cudaDevicePosition);
    cudaFree(cudaDeviceVelocity);
    cudaFree(cudaDeviceColor);
    cudaFree(cudaDeviceRadius);
    cudaFree(cudaDeviceImageData);
    cudaFree(d_tile_offsets);
    // d_tile_circle_indices_ptr points to memory managed by Thrust vector in render()
}

const Image* CudaRenderer::getImage() {
    // Ensure all GPU work is done before copy
    cudaCheckError(cudaDeviceSynchronize());

    // Copy rendered image from device memory to host
    cudaCheckError(cudaMemcpy(image->data, cudaDeviceImageData,
                              sizeof(float) * 4 * image->width * image->height,
                              cudaMemcpyDeviceToHost));
    return image;
}

void CudaRenderer::loadScene(SceneName scene) {
    sceneName = scene;
    // Free existing host data if reloading
    if (position) { delete [] position; position = NULL; }
    if (velocity) { delete [] velocity; velocity = NULL; }
    if (color)    { delete [] color;    color = NULL;    }
    if (radius)   { delete [] radius;   radius = NULL;   }
    loadCircleScene(sceneName, numCircles, position, velocity, color, radius);
     printf("Loaded scene %d with %d circles.\n", sceneName, numCircles);
}

void CudaRenderer::allocOutputImage(int width, int height) {
    if (image) delete image;
    image = new Image(width, height);
}

void CudaRenderer::setup() {

    // Basic CUDA device setup (omit printing for brevity)
    int deviceCount = 0;
    cudaCheckError(cudaGetDeviceCount(&deviceCount));
    if (deviceCount == 0) {
        fprintf(stderr, "Error: No CUDA-capable devices found.\n");
        exit(EXIT_FAILURE);
    }
    // ... (Optional: Print device properties) ...

    // Free existing device memory before allocating new (if setup is called multiple times)
    cudaFree(cudaDevicePosition); cudaDevicePosition = NULL;
    cudaFree(cudaDeviceVelocity); cudaDeviceVelocity = NULL;
    cudaFree(cudaDeviceColor);    cudaDeviceColor = NULL;
    cudaFree(cudaDeviceRadius);   cudaDeviceRadius = NULL;
    cudaFree(cudaDeviceImageData);cudaDeviceImageData = NULL;
    cudaFree(d_tile_offsets);     d_tile_offsets = NULL;

    // Allocate basic device memory
    if (numCircles > 0) {
        cudaCheckError(cudaMalloc(&cudaDevicePosition, sizeof(float) * 3 * numCircles));
        cudaCheckError(cudaMalloc(&cudaDeviceVelocity, sizeof(float) * 3 * numCircles));
        cudaCheckError(cudaMalloc(&cudaDeviceColor,    sizeof(float) * 3 * numCircles));
        cudaCheckError(cudaMalloc(&cudaDeviceRadius,   sizeof(float) * numCircles));

        // Copy basic data from host to device
        cudaCheckError(cudaMemcpy(cudaDevicePosition, position, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
        cudaCheckError(cudaMemcpy(cudaDeviceVelocity, velocity, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
        cudaCheckError(cudaMemcpy(cudaDeviceColor,    color,    sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
        cudaCheckError(cudaMemcpy(cudaDeviceRadius,   radius,   sizeof(float) * numCircles,   cudaMemcpyHostToDevice));
    }

    // Allocate image buffer on device
    if (image && image->width > 0 && image->height > 0) {
        cudaCheckError(cudaMalloc(&cudaDeviceImageData, sizeof(float) * 4 * image->width * image->height));
    } else {
         fprintf(stderr, "Error: Output image not allocated before setup.\n");
         exit(EXIT_FAILURE);
    }


    // Calculate tile grid dimensions
    numTilesX = (image->width + TILE_DIM_X - 1) / TILE_DIM_X;
    numTilesY = (image->height + TILE_DIM_Y - 1) / TILE_DIM_Y;
    int num_tiles = numTilesX * numTilesY;

    // Allocate persistent device memory for tile offsets (+1 for sentinel)
    cudaCheckError(cudaMalloc(&d_tile_offsets, sizeof(int) * (num_tiles + 1)));

    // Copy noise/color lookup tables to constant memory (unchanged)
    int* permX;
    int* permY;
    float* value1D;
    getNoiseTables(&permX, &permY, &value1D);
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseXPermutationTable, permX, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseYPermutationTable, permY, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoise1DValueTable, value1D, sizeof(float) * 256));

    float lookupTable[COLOR_MAP_SIZE][3] = {
        {1.f, 1.f, 1.f}, {1.f, 1.f, 1.f}, {.8f, .9f, 1.f},
        {.8f, .9f, 1.f}, {.8f, 0.8f, 1.f},
    };
    cudaCheckError(cudaMemcpyToSymbol(cuConstColorRamp, lookupTable, sizeof(float) * 3 * COLOR_MAP_SIZE));

    printf("Setup complete. Image: %dx%d, Tiles: %dx%d\n", image->width, image->height, numTilesX, numTilesY);
}

void CudaRenderer::render() {

    if (numCircles == 0 || !image || !cudaDeviceImageData) {
         //printf("Render: Skipping due to 0 circles or uninitialized image/buffer.\n");
         return; // Nothing to render or nowhere to render it
    }

    // Use Thrust device vectors for temporary storage (RAII for memory management)
    thrust::device_vector<int> d_pair_counts_per_circle;
    thrust::device_vector<int> d_pair_write_offsets;
    thrust::device_vector<int> d_temp_pair_keys;
    thrust::device_vector<int> d_temp_pair_values; // Will hold sorted circle indices

    try {
        // Resize count/offset vectors
        d_pair_counts_per_circle.resize(numCircles);
        d_pair_write_offsets.resize(numCircles);
        cudaCheckError(cudaGetLastError()); // Check OOM

        // 1. Count overlaps per circle
        dim3 blockDim1D(256);
        dim3 gridDim1D((numCircles + blockDim1D.x - 1) / blockDim1D.x);
        kernelGeneratePairCounts<<<gridDim1D, blockDim1D>>>(
            numCircles, cudaDevicePosition, cudaDeviceRadius,
            image->width, image->height, numTilesX, numTilesY,
            thrust::raw_pointer_cast(d_pair_counts_per_circle.data()));
        cudaCheckError(cudaGetLastError());
        // Sync required before scan
        cudaCheckError(cudaDeviceSynchronize());

        // 2. Scan counts to get write offsets and total pairs
        thrust::exclusive_scan(thrust::device,
                               d_pair_counts_per_circle.begin(), d_pair_counts_per_circle.end(),
                               d_pair_write_offsets.begin());
        cudaCheckError(cudaGetLastError());
        cudaCheckError(cudaDeviceSynchronize()); // Ensure scan completes

        // Calculate total number of pairs needed
        int last_offset = 0;
        int last_count = 0;
        if (numCircles > 0) {
            // Copy the last elements back to host to calculate total size
            // Avoids potential issues with device-side reduction/access
            last_offset = d_pair_write_offsets[numCircles - 1]; // Reads from device memory
            last_count = d_pair_counts_per_circle[numCircles - 1]; // Reads from device memory
            cudaCheckError(cudaDeviceSynchronize()); // Ensure copies complete
        }
        total_pairs = last_offset + last_count;

        //printf("Render: Found %zu total circle-tile overlaps.\n", total_pairs);

        // Handle case where no circles overlap any tiles
        if (total_pairs == 0) {
             // Image already cleared, so just return
             // No need to proceed further with binning/rendering steps for circles
             // printf("Render: No circle-tile overlaps found. Skipping rest of render.\n");
             return;
        }

        // Resize temporary buffers to actual size needed
        d_temp_pair_keys.resize(total_pairs);
        d_temp_pair_values.resize(total_pairs);
        cudaCheckError(cudaGetLastError()); // Check potential OOM on resize

        // 3. Write the pairs
        kernelWriteCircleTilePairs<<<gridDim1D, blockDim1D>>>(
            numCircles, cudaDevicePosition, cudaDeviceRadius,
            image->width, image->height, numTilesX, numTilesY,
            thrust::raw_pointer_cast(d_pair_write_offsets.data()),
            thrust::raw_pointer_cast(d_temp_pair_keys.data()),
            thrust::raw_pointer_cast(d_temp_pair_values.data()));
        cudaCheckError(cudaGetLastError());
        cudaCheckError(cudaDeviceSynchronize()); // Ensure pairs are written before sort

        // 4. Sort pairs: tile_idx is key, circle_idx is value
        thrust::sort_by_key(thrust::device,
                            d_temp_pair_keys.begin(), d_temp_pair_keys.end(),
                            d_temp_pair_values.begin());
        cudaCheckError(cudaGetLastError());
        cudaCheckError(cudaDeviceSynchronize()); // Ensure sort completes
        // Now d_temp_pair_values holds the sorted circle indices (our d_tile_circle_indices)
        d_tile_circle_indices_ptr = thrust::raw_pointer_cast(d_temp_pair_values.data());

        // 5. Reduce keys to get unique tiles and counts
        int num_tiles = numTilesX * numTilesY;
        // Allocate temporary vectors for unique keys/counts (max size = total_pairs)
        thrust::device_vector<int> d_unique_tile_keys(total_pairs);
        thrust::device_vector<int> d_counts_for_unique_tiles(total_pairs);

        thrust::pair<thrust::device_vector<int>::iterator,
                     thrust::device_vector<int>::iterator> new_end;

        new_end = thrust::reduce_by_key(thrust::device,
                                        d_temp_pair_keys.begin(), d_temp_pair_keys.end(),
                                        thrust::make_constant_iterator(1), // Value iterator (count 1 per key)
                                        d_unique_tile_keys.begin(), // Output keys iterator
                                        d_counts_for_unique_tiles.begin()); // Output values (counts) iterator
        cudaCheckError(cudaGetLastError());
        cudaCheckError(cudaDeviceSynchronize()); // Ensure reduce completes

        int num_unique_tiles = new_end.first - d_unique_tile_keys.begin();
        //printf("Render: Found %d unique overlapping tiles.\n", num_unique_tiles);

        // 6. Build final tile offsets array on host
        thrust::host_vector<int> h_unique_tile_keys(num_unique_tiles);
        thrust::host_vector<int> h_counts_for_unique_tiles(num_unique_tiles);
        thrust::copy(thrust::device, d_unique_tile_keys.begin(), d_unique_tile_keys.begin() + num_unique_tiles, h_unique_tile_keys.begin());
        thrust::copy(thrust::device, d_counts_for_unique_tiles.begin(), d_counts_for_unique_tiles.begin() + num_unique_tiles, h_counts_for_unique_tiles.begin());
        cudaCheckError(cudaDeviceSynchronize()); // Ensure copies complete

        // Compute exclusive scan on host for unique tile counts
        thrust::host_vector<int> h_offsets_for_unique_tiles(num_unique_tiles);
        std::exclusive_scan(h_counts_for_unique_tiles.begin(), h_counts_for_unique_tiles.end(), h_offsets_for_unique_tiles.begin(), 0);

        // Build the full offset map on host
        thrust::host_vector<int> h_tile_offsets(num_tiles + 1, -1); // Final offsets, init with -1
        h_tile_offsets[0] = 0; // Tile 0 always starts at offset 0

        // Scatter the calculated offsets based on unique tile keys
        for (int i = 0; i < num_unique_tiles; ++i) {
            int tile_idx = h_unique_tile_keys[i];
            if (tile_idx >= 0 && tile_idx < num_tiles) { // Bounds check
                 h_tile_offsets[tile_idx] = h_offsets_for_unique_tiles[i];
            } else {
                 fprintf(stderr, "Error: Invalid tile index %d found during offset generation.\n", tile_idx);
            }
        }

        // Fill gaps by propagating the previous valid offset
        int last_valid_offset = 0;
        for (int i = 0; i < num_tiles; ++i) {
             if (h_tile_offsets[i] != -1) {
                  last_valid_offset = h_tile_offsets[i];
             } else {
                  h_tile_offsets[i] = last_valid_offset; // Fill gap with last known offset
             }
        }
        h_tile_offsets[num_tiles] = total_pairs; // Set the final sentinel offset

        // Copy final offsets to persistent device memory
        cudaCheckError(cudaMemcpy(d_tile_offsets, h_tile_offsets.data(), // Use .data() for raw pointer
                                  sizeof(int) * (num_tiles + 1), cudaMemcpyHostToDevice));
        cudaCheckError(cudaDeviceSynchronize()); // Ensure copy is done before kernel launch

        // 7. Launch the rendering kernel
        dim3 renderBlockDim(TILE_DIM_X, TILE_DIM_Y);
        dim3 renderGridDim(numTilesX, numTilesY);

        kernelRenderTilesBinned<<<renderGridDim, renderBlockDim>>>(
            image->width, image->height, cudaDeviceImageData,
            numTilesX, numTilesY, // Pass grid dims
            d_tile_offsets,
            d_tile_circle_indices_ptr, // Pass raw pointer to sorted indices
            sceneName, // Pass sceneName directly
            numCircles, // Pass numCircles directly
            cudaDevicePosition, cudaDeviceColor, cudaDeviceRadius // Pass basic data directly
        );
        cudaCheckError(cudaGetLastError());
        // Final synchronize to ensure rendering is complete before returning control
        // (e.g., before getImage() might be called)
        cudaCheckError(cudaDeviceSynchronize());

    } catch (const thrust::system_error& e) {
        fprintf(stderr, "Thrust error in render(): %s\n", e.what());
        // Handle error, maybe exit or try a fallback
        cudaDeviceReset(); // Reset device state on fatal error
        exit(1);
    } catch (const std::runtime_error& e) {
        fprintf(stderr, "Runtime error in render(): %s\n", e.what());
        cudaDeviceReset();
        exit(1);
    } catch (const std::bad_alloc& e) {
        // This catches host allocation errors (e.g., resizing host_vectors)
        fprintf(stderr, "Host allocation error (std::bad_alloc) in render(): %s\n", e.what());
        cudaDeviceReset();
        exit(1);
    }
    // Thrust device_vectors automatically freed when they go out of scope (RAII)
    d_tile_circle_indices_ptr = NULL; // Invalidate pointer once vector is destroyed
}

__global__ void kernelRenderCirclesOrdered() {
    int pixelX = blockIdx.x * blockDim.x + threadIdx.x;
    int pixelY = blockIdx.y * blockDim.y + threadIdx.y;
    
    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;
    
    // Check if this thread's pixel is within the image bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;
    
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float2 pixelCenterNorm = make_float2(invWidth * (static_cast<float>(pixelX) + 0.5f),
                                        invHeight * (static_cast<float>(pixelY) + 0.5f));
    
    // Get a pointer to this pixel's color data
    float4* imgPtr = (float4*)(&cuConstRendererParams.imageData[4 * (pixelY * imageWidth + pixelX)]);
    
    // Process all circles in order
    for (int circleIndex = 0; circleIndex < cuConstRendererParams.numCircles; circleIndex++) {
        int index3 = 3 * circleIndex;
        
        // Read circle position and radius
        float3 p = *(float3*)(&cuConstRendererParams.position[index3]);
        float rad = cuConstRendererParams.radius[circleIndex];
        
        // Compute the distance from pixel center to circle center
        float diffX = p.x - pixelCenterNorm.x;
        float diffY = p.y - pixelCenterNorm.y;
        float pixelDist = diffX * diffX + diffY * diffY;
        float maxDist = rad * rad;
        
        // If pixel is within the circle, update its color
        if (pixelDist <= maxDist) {
            shadePixel(circleIndex, pixelCenterNorm, p, imgPtr);
        }
    }
}
