<div class="problem-section">
<h3>problem description:</h3>
<p>The current rendering kernel, <code>kernelRenderCirclesTiled</code>, assigns each thread to a pixel and iterates through all circles for that pixel. While it uses a conservative tile-based culling check (<code>circleInBoxConservative</code>) to potentially skip processing circles that don't overlap the entire thread block's tile, each thread within the block still independently reads the position and radius data for every non-culled circle from global memory. For scenes with a large number of circles, this results in massive redundant global memory reads, as multiple threads within the same block repeatedly fetch the same circle data. Global memory access is slow, making this a significant performance bottleneck.</p>
</div>

<div class="problem-section">
<h3>problem reasoning:</h3>
<p>I analyzed the <code>kernelRenderCirclesTiled</code> kernel. The outer loop iterates from <code>circleIndex = 0</code> to <code>numCircles</code>. Inside this loop, each thread reads circle position (<code>cuConstRendererParams.position[3 * circleIndex]</code>) and radius (<code>cuConstRendererParams.radius[circleIndex]</code>) from global memory. Although the <code>circleInBoxConservative</code> check helps prune circles at the tile level, all threads within a block that pass this check will perform these global memory reads for the same circle. Since threads in a block execute on the same Streaming Multiprocessor (SM) and often access memory similarly, there's a high degree of redundant traffic to the slow global memory. Accessing shared memory is significantly faster than global memory. By caching frequently accessed circle data (position and radius) in shared memory, we can reduce the number of global memory transactions dramatically, replacing many slow global reads with fewer global reads followed by many fast shared memory reads.</p>
</div>

<div class="problem-section">
<h3>proposed remedy:</h3>
<p>Implement a new kernel, <code>kernelRenderCirclesTiledShared</code>, that utilizes shared memory to cache circle data (position and radius) for processing within a thread block.
<ol>
    <li>Maintain the tile-based approach where each thread block processes a tile of pixels (e.g., 16x16) and each thread is responsible for one pixel.</li>
    <li>Introduce shared memory arrays within the kernel to store a chunk of circle positions and radii. The size of the chunk can be equal to the number of threads in the block (e.g., 256).</li>
    <li>Modify the main loop to iterate through circles in chunks.</li>
    <li>Inside the chunk loop, have threads within the block cooperatively load the position and radius data for the current chunk of circles from global memory into the shared memory arrays. Use <code>__syncthreads()</code> to ensure loading is complete before proceeding.</li>
    <li>After loading, each thread iterates through the circles currently cached in shared memory.</li>
    <li>For each circle in shared memory, perform the <code>circleInBoxConservative</code> test using the cached data and the tile boundaries.</li>
    <li>If the test passes, call a slightly modified <code>shadePixel</code> function, passing the circle's position and radius directly from shared memory (instead of having <code>shadePixel</code> read them from global memory). The global <code>circleIndex</code> is still needed for color lookup.</li>
    <li>Use <code>__syncthreads()</code> again before loading the next chunk to avoid race conditions on the shared memory arrays.</li>
    <li>Modify the <code>shadePixel</code> function signature to accept position and radius as parameters.</li>
    <li>Update <code>CudaRenderer::render</code> to launch this new <code>kernelRenderCirclesTiledShared</code> kernel.</li>
</ol>
</p>
</div>

<div class="problem-section">
<h3>remedy reasoning:</h3>
<p>1) Why do you think this solution will fix the problem?</p>
<p>This solution directly addresses the identified bottleneck: redundant global memory reads of circle data. By loading chunks of circle data into shared memory once per block per chunk, we replace potentially `numCircles * threads_per_block` global reads of position/radius with approximately `numCircles` global reads (coalesced across threads during loading) plus `numCircles * threads_per_block` fast shared memory reads. Since shared memory latency is orders of magnitude lower than global memory latency, and bandwidth is much higher, this significantly reduces the time spent waiting for data, improving overall kernel execution time, especially for scenes with many circles where memory bandwidth is often the limiting factor.</p>

<p>2) What do you expect the program results to be when after this change is implemented?</p>
<p>I expect the program to remain correct, passing all correctness checks, because the fundamental rendering logic (processing circles in order, accumulating color per pixel) is preserved. The order of operations for blending within a pixel remains unchanged. Atomicity is still guaranteed as each thread writes only to its own pixel at the very end. In terms of performance, I expect a significant speedup across most test cases, particularly those with a large number of circles (`rand10k`, `rand100k`, `pattern`, `snowsingle`, `biglittle`, `rand1M`, `micro2M`). The improvement will stem directly from the reduced global memory traffic. For the `rgb` test case with only 3 circles, the overhead of setting up shared memory might slightly increase the runtime compared to the previous version, or the difference might be negligible, but it should still be very fast. The goal is substantial improvement on the larger, more demanding test cases, bringing the runtime closer to the reference solution.</p>
</div>

// kernelClearImageSnowflake -- (CUDA device code)
//
// Clear the image, setting the image to the white-gray gradation that
// is used in the snowflake image
__global__ void kernelClearImageSnowflake() {

    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    int width = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height)
        return;

    int offset = 4 * (imageY * width + imageX);
    float shade = .4f + .45f * static_cast<float>(height-imageY) / height;
    float4 value = make_float4(shade, shade, shade, 1.f);

    // write to global memory: As an optimization, I use a float4
    // store, that results in more efficient code than if I coded this
    // up as four seperate fp32 stores.
    *(float4*)(&cuConstRendererParams.imageData[offset]) = value;
}

// kernelClearImage --  (CUDA device code)
//
// Clear the image, setting all pixels to the specified color rgba
__global__ void kernelClearImage(float r, float g, float b, float a) {

    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    int width = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height)
        return;

    int offset = 4 * (imageY * width + imageX);
    float4 value = make_float4(r, g, b, a);

    // write to global memory: As an optimization, I use a float4
    // store, that results in more efficient code than if I coded this
    // up as four seperate fp32 stores.
    *(float4*)(&cuConstRendererParams.imageData[offset]) = value;
}

// kernelAdvanceFireWorks
//
// Update the position of the fireworks (if circle is firework)
__global__ void kernelAdvanceFireWorks() {
    const float dt = 1.f / 60.f;
    const float pi = 3.14159f;
    const float maxDist = 0.25f;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;
    float* radius = cuConstRendererParams.radius;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;

    if (0 <= index && index < NUM_FIREWORKS) { // firework center; no update
        return;
    }

    // determine the fire-work center/spark indices
    int fIdx = (index - NUM_FIREWORKS) / NUM_SPARKS;
    int sfIdx = (index - NUM_FIREWORKS) % NUM_SPARKS;

    int index3i = 3 * fIdx;
    int sIdx = NUM_FIREWORKS + fIdx * NUM_SPARKS + sfIdx;
    int index3j = 3 * sIdx;

    float cx = position[index3i];
    float cy = position[index3i+1];

    // update position
    position[index3j] += velocity[index3j] * dt;
    position[index3j+1] += velocity[index3j+1] * dt;

    // fire-work sparks
    float sx = position[index3j];
    float sy = position[index3j+1];

    // compute vector from firework-spark
    float cxsx = sx - cx;
    float cysy = sy - cy;

    // compute distance from fire-work
    float dist = sqrtf(cxsx * cxsx + cysy * cysy); // Use sqrtf
    if (dist > maxDist) { // restore to starting position
        // random starting position on fire-work's rim
        float angle = (sfIdx * 2 * pi)/NUM_SPARKS;
        float sinA = sinf(angle); // Use sinf
        float cosA = cosf(angle); // Use cosf
        float x = cosA * radius[fIdx];
        float y = sinA * radius[fIdx];

        position[index3j] = position[index3i] + x;
        position[index3j+1] = position[index3i+1] + y;
        position[index3j+2] = 0.0f;

        // travel scaled unit length
        velocity[index3j] = cosA/5.0f;
        velocity[index3j+1] = sinA/5.0f;
        velocity[index3j+2] = 0.0f;
    }
}

// kernelAdvanceHypnosis
//
// Update the radius/color of the circles
__global__ void kernelAdvanceHypnosis() {
    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;

    float* radius = cuConstRendererParams.radius;

    float cutOff = 0.5f;
    // place circle back in center after reaching threshold radisus
    if (radius[index] > cutOff) {
        radius[index] = 0.02f;
    } else {
        radius[index] += 0.01f;
    }
}


// kernelAdvanceBouncingBalls
//
// Update the positino of the balls
__global__ void kernelAdvanceBouncingBalls() {
    const float dt = 1.f / 60.f;
    const float kGravity = -2.8f; // sorry Newton
    const float kDragCoeff = -0.8f;
    const float epsilon = 0.001f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;

    int index3 = 3 * index;
    // reverse velocity if center position < 0
    float oldVelocity = velocity[index3+1];
    float oldPosition = position[index3+1];

    if (oldVelocity == 0.f && oldPosition == 0.f) { // stop-condition
        return;
    }

    if (position[index3+1] < 0 && oldVelocity < 0.f) { // bounce ball
        velocity[index3+1] *= kDragCoeff;
    }

    // update velocity: v = u + at (only along y-axis)
    velocity[index3+1] += kGravity * dt;

    // update positions (only along y-axis)
    position[index3+1] += velocity[index3+1] * dt;

    if (fabsf(velocity[index3+1] - oldVelocity) < epsilon // Use fabsf
        && oldPosition < 0.0f
        && fabsf(position[index3+1]-oldPosition) < epsilon) { // stop ball
        velocity[index3+1] = 0.f;
        position[index3+1] = 0.f;
    }
}

// kernelAdvanceSnowflake -- (CUDA device code)
//
// move the snowflake animation forward one time step.  Updates circle
// positions and velocities.  Note how the position of the snowflake
// is reset if it moves off the left, right, or bottom of the screen.
__global__ void kernelAdvanceSnowflake() {

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    const float dt = 1.f / 60.f;
    const float kGravity = -1.8f; // sorry Newton
    const float kDragCoeff = 2.f;

    int index3 = 3 * index;

    float* positionPtr = &cuConstRendererParams.position[index3];
    float* velocityPtr = &cuConstRendererParams.velocity[index3];

    // loads from global memory
    float3 position = *((float3*)positionPtr);
    float3 velocity = *((float3*)velocityPtr);

    // hack to make farther circles move more slowly, giving the
    // illusion of parallax
    float forceScaling = fminf(fmaxf(1.f - position.z, .1f), 1.f); // clamp, use fminf/fmaxf

    // add some noise to the motion to make the snow flutter
    float3 noiseInput;
    noiseInput.x = 10.f * position.x;
    noiseInput.y = 10.f * position.y;
    noiseInput.z = 255.f * position.z;
    float2 noiseForce = cudaVec2CellNoise(noiseInput, index);
    noiseForce.x *= 7.5f;
    noiseForce.y *= 5.f;

    // drag
    float2 dragForce;
    dragForce.x = -1.f * kDragCoeff * velocity.x;
    dragForce.y = -1.f * kDragCoeff * velocity.y;

    // update positions
    position.x += velocity.x * dt;
    position.y += velocity.y * dt;

    // update velocities
    velocity.x += forceScaling * (noiseForce.x + dragForce.y) * dt;
    velocity.y += forceScaling * (kGravity + noiseForce.y + dragForce.y) * dt;

    float radius = cuConstRendererParams.radius[index];

    // if the snowflake has moved off the left, right or bottom of
    // the screen, place it back at the top and give it a
    // pseudorandom x position and velocity.
    if ( (position.y + radius < 0.f) ||
         (position.x + radius) < -0.f ||
         (position.x - radius) > 1.f)
    {
        noiseInput.x = 255.f * position.x;
        noiseInput.y = 255.f * position.y;
        noiseInput.z = 255.f * position.z;
        noiseForce = cudaVec2CellNoise(noiseInput, index);

        position.x = .5f + .5f * noiseForce.x;
        position.y = 1.35f + radius;

        // restart from 0 vertical velocity.  Choose a
        // pseudo-random horizontal velocity.
        velocity.x = 2.f * noiseForce.y;
        velocity.y = 0.f;
    }

    // store updated positions and velocities to global memory
    *((float3*)positionPtr) = position;
    *((float3*)velocityPtr) = velocity;
}


// Modified shadePixel to accept position and radius
// This avoids redundant global memory reads inside this frequently called function
__device__ __inline__ void
shadePixel(int circleIndex, float2 pixelCenter, float3 p, float rad, float4& pixelValue) { // Added 'p' and 'rad' parameters

    float diffX = p.x - pixelCenter.x;
    float diffY = p.y - pixelCenter.y;
    float pixelDist = diffX * diffX + diffY * diffY;

    // Radius 'rad' is now passed in
    float maxDist = rad * rad;

    // circle does not contribute to the image if pixel center is outside
    if (pixelDist > maxDist)
        return;

    float3 rgb;
    float alpha;

    // there is a non-zero contribution. Now compute the shading value

    if (cuConstRendererParams.sceneName == SNOWFLAKES ||
        cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {

        const float kCircleMaxAlpha = .5f;
        const float falloffScale = 4.f;

        // Use sqrtf for single-precision float
        float normPixelDist = sqrtf(pixelDist) / rad;
        rgb = lookupColor(normPixelDist);

        // Use p.z passed in
        float maxAlpha = .6f + .4f * (1.f - p.z);
        // Use fmaxf/fminf for single-precision float
        maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f); // kCircleMaxAlpha * clamped value
        // Use expf for single-precision float
        alpha = maxAlpha * expf(-1.f * falloffScale * normPixelDist * normPixelDist);

    } else {
        // simple: each circle has an assigned color
        int index3 = 3 * circleIndex;
        // Color still needs to be fetched from global memory using circleIndex
        rgb = *(float3*)&(cuConstRendererParams.color[index3]);
        alpha = .5f; // Assuming a constant alpha for non-snowflake scenes as before
    }

    // Blend the color contribution into the pixelValue
    float oneMinusAlpha = 1.f - alpha;
    // Read existing color components directly from pixelValue (passed by reference)
    pixelValue.x = alpha * rgb.x + oneMinusAlpha * pixelValue.x;
    pixelValue.y = alpha * rgb.y + oneMinusAlpha * pixelValue.y;
    pixelValue.z = alpha * rgb.z + oneMinusAlpha * pixelValue.z;
    // Accumulate alpha as done in the original 'correct' code.
    // Note: This is not standard alpha compositing for the alpha channel itself,
    // but we preserve the original behaviour.
    pixelValue.w = alpha + pixelValue.w;
}


#define TILE_DIM 16
#define BLOCK_SIZE (TILE_DIM * TILE_DIM) // 256 threads per block
#define SHARED_MEM_CHUNK_SIZE BLOCK_SIZE // Process chunks of 256 circles

// kernelRenderCirclesTiledShared -- (CUDA device code)
//
// Each thread renders a single pixel.
// Uses tile-based culling.
// Uses shared memory to cache circle data (position, radius) within a block.
// Processes circles in order for the pixel.
// Accumulates color locally in registers and writes once to global memory.
__global__ void kernelRenderCirclesTiledShared() {
    // Calculate global pixel coordinates for this thread
    int pixelX = blockIdx.x * TILE_DIM + threadIdx.x;
    int pixelY = blockIdx.y * TILE_DIM + threadIdx.y;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if this thread's pixel is within the image bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;

    // Calculate linear thread index within the block (0 to BLOCK_SIZE-1)
    int tid = threadIdx.y * TILE_DIM + threadIdx.x;

    // Shared memory for caching a chunk of circle data
    // Stores position (float3) and radius (float) for SHARED_MEM_CHUNK_SIZE circles
    __shared__ float3 sharedPos[SHARED_MEM_CHUNK_SIZE];
    __shared__ float sharedRad[SHARED_MEM_CHUNK_SIZE];

    // Precompute inverse image dimensions for normalization
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;

    // Calculate normalized coordinates [0, 1] for the center of this thread's pixel
    float2 pixelCenterNorm = make_float2(invWidth * (static_cast<float>(pixelX) + 0.5f),
                                         invHeight * (static_cast<float>(pixelY) + 0.5f));

    // Calculate the normalized boundaries [0, 1] of this thread's tile (block)
    // These are used for the conservative tile culling check
    float tileL = invWidth * (blockIdx.x * TILE_DIM);
    float tileR = invWidth * ((blockIdx.x + 1) * TILE_DIM);
    float tileB = invHeight * (blockIdx.y * TILE_DIM);
    float tileT = invHeight * ((blockIdx.y + 1) * TILE_DIM);

    // Get a pointer to this pixel's color data (float4) in global memory
    int pixelOffset = 4 * (pixelY * imageWidth + pixelX);
    float4* imgPtrGlobal = (float4*)(&cuConstRendererParams.imageData[pixelOffset]);

    // Initialize accumulated color locally in registers for this thread
    // Start with the initial background color for this pixel (set by clearImage)
    float4 accumulatedColor = *imgPtrGlobal;

    int numCircles = cuConstRendererParams.numCircles;

    // Process circles in chunks to fit into shared memory
    for (int chunkStart = 0; chunkStart < numCircles; chunkStart += SHARED_MEM_CHUNK_SIZE) {

        // Cooperatively load circle data for the current chunk into shared memory
        // Each thread loads data for one circle in the chunk
        int globalCircleIdxToLoad = chunkStart + tid;
        if (globalCircleIdxToLoad < numCircles) {
            // Load position (float3) and radius (float) from global memory
            // Note: Direct cast assumes alignment, which is generally true for float3 on device.
            sharedPos[tid] = *(float3*)(&cuConstRendererParams.position[3 * globalCircleIdxToLoad]);
            sharedRad[tid] = cuConstRendererParams.radius[globalCircleIdxToLoad];
        }

        // Synchronize block threads to ensure shared memory is fully loaded
        // before any thread tries to read data loaded by others.
        __syncthreads();

        // Determine the number of valid circles in this specific chunk
        // (can be less than SHARED_MEM_CHUNK_SIZE for the last chunk)
        int circlesInChunk = min(SHARED_MEM_CHUNK_SIZE, numCircles - chunkStart);

        // Iterate through the circles loaded in shared memory for this chunk
        // All threads in the block iterate through the same shared data
        for (int i = 0; i < circlesInChunk; ++i) {
            // Get circle data (position, radius) from shared memory
            float3 p_shared = sharedPos[i];
            float rad_shared = sharedRad[i];
            int globalCircleIndex = chunkStart + i; // Get the original global index

            // *** Tile Culling Check (using shared memory data) ***
            // Use conservative test: if circle doesn't overlap the tile's bounding box,
            // skip the more expensive shadePixel call for this circle.
            // This check is performed by *every* thread based on shared data.
            if (circleInBoxConservative(p_shared.x, p_shared.y, rad_shared, tileL, tileR, tileT, tileB)) {

                // If the circle might overlap the tile, call shadePixel.
                // shadePixel performs the precise point-in-circle test for this thread's pixel.
                // Pass data from shared memory (p_shared, rad_shared) and the global index.
                shadePixel(globalCircleIndex, pixelCenterNorm, p_shared, rad_shared, accumulatedColor);
            }
        } // End loop over circles in the current chunk

        // Synchronize before loading the next chunk.
        // Ensures all threads are done reading the current shared memory chunk
        // before some threads start overwriting it with the next chunk's data.
        __syncthreads();

    } // End loop over chunks

    // Write the final accumulated color from registers to global memory ONCE per pixel
    *imgPtrGlobal = accumulatedColor;
}

CudaRenderer::CudaRenderer() {
    image = NULL;

    numCircles = 0;
    position = NULL;
    velocity = NULL;
    color = NULL;
    radius = NULL;

    cudaDevicePosition = NULL;
    cudaDeviceVelocity = NULL;
    cudaDeviceColor = NULL;
    cudaDeviceRadius = NULL;
    cudaDeviceImageData = NULL;
}

CudaRenderer::~CudaRenderer() {

    if (image) {
        delete image;
    }

    if (position) {
        delete [] position;
        delete [] velocity;
        delete [] color;
        delete [] radius;
    }

    if (cudaDevicePosition) {
        cudaFree(cudaDevicePosition);
        cudaFree(cudaDeviceVelocity);
        cudaFree(cudaDeviceColor);
        cudaFree(cudaDeviceRadius);
        cudaFree(cudaDeviceImageData);
    }
}

const Image*
CudaRenderer::getImage() {

    // need to copy contents of the rendered image from device memory
    // before we expose the Image object to the caller

    cudaCheckError(cudaMemcpy(image->data,
                                 cudaDeviceImageData,
                                 sizeof(float) * 4 * image->width * image->height,
                                 cudaMemcpyDeviceToHost));

    return image;
}

void
CudaRenderer::loadScene(SceneName scene) {
    sceneName = scene;
    loadCircleScene(sceneName, numCircles, position, velocity, color, radius);
}

void
CudaRenderer::setup() {

    int deviceCount = 0;
    std::string name;
    cudaCheckError(cudaGetDeviceCount(&deviceCount));

    printf("---------------------------------------------------------\n");
    printf("Initializing CUDA for CudaRenderer\n");
    printf("Found %d CUDA devices\n", deviceCount);

    for (int i=0; i<deviceCount; i++) {
        cudaDeviceProp deviceProps;
        cudaCheckError(cudaGetDeviceProperties(&deviceProps, i));
        name = deviceProps.name;
        printf("Device %d: %s\n", i, deviceProps.name);
        printf("   SMs:        %d\n", deviceProps.multiProcessorCount);
        printf("   Global mem: %.0f MB\n", static_cast<float>(deviceProps.totalGlobalMem) / (1024 * 1024));
        printf("   CUDA Cap:   %d.%d\n", deviceProps.major, deviceProps.minor);
    }
    printf("---------------------------------------------------------\n");

    // By this time the scene should be loaded.  Now copy all the key
    // data structures into device memory so they are accessible to
    // CUDA kernels
    //
    // See the CUDA Programmer's Guide for descriptions of
    // cudaMalloc and cudaMemcpy

    cudaCheckError(cudaMalloc(&cudaDevicePosition, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceVelocity, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceColor, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceRadius, sizeof(float) * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceImageData, sizeof(float) * 4 * image->width * image->height));

    cudaCheckError(cudaMemcpy(cudaDevicePosition, position, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceVelocity, velocity, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceColor, color, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceRadius, radius, sizeof(float) * numCircles, cudaMemcpyHostToDevice));

    // Initialize parameters in constant memory.
    GlobalConstants params;
    params.sceneName = sceneName;
    params.numCircles = numCircles;
    params.imageWidth = image->width;
    params.imageHeight = image->height;
    params.position = cudaDevicePosition;
    params.velocity = cudaDeviceVelocity;
    params.color = cudaDeviceColor;
    params.radius = cudaDeviceRadius;
    params.imageData = cudaDeviceImageData;

    cudaCheckError(cudaMemcpyToSymbol(cuConstRendererParams, &params, sizeof(GlobalConstants)));

    // also need to copy over the noise lookup tables, so we can
    // implement noise on the GPU
    int* permX;
    int* permY;
    float* value1D;
    getNoiseTables(&permX, &permY, &value1D);
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseXPermutationTable, permX, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseYPermutationTable, permY, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoise1DValueTable, value1D, sizeof(float) * 256));

    // last, copy over the color table that's used by the shading
    // function for circles in the snowflake demo

    float lookupTable[COLOR_MAP_SIZE][3] = {
        {1.f, 1.f, 1.f},
        {1.f, 1.f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, 0.8f, 1.f},
    };

    cudaCheckError(cudaMemcpyToSymbol(cuConstColorRamp, lookupTable, sizeof(float) * 3 * COLOR_MAP_SIZE));

}

// allocOutputImage --
//
// Allocate buffer the renderer will render into.  Check status of
// image first to avoid memory leak.
void
CudaRenderer::allocOutputImage(int width, int height) {

    if (image)
        delete image;
    image = new Image(width, height);
}

// clearImage --
//
// Clear's the renderer's target image.  The state of the image after
// the clear depends on the scene being rendered.
void
CudaRenderer::clearImage() {
    // Use 16x16 blocks (256 threads) for clearing
    dim3 blockDim(16, 16, 1);
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
        kernelClearImageSnowflake<<<gridDim, blockDim>>>();
    } else {
        // Clear with alpha = 1, consistent with previous correct implementation
        // Set background to white (1,1,1) with alpha 1
        kernelClearImage<<<gridDim, blockDim>>>(1.f, 1.f, 1.f, 1.f);
    }
    // Check for errors after kernel launch, useful for debugging
    cudaError_t err = cudaGetLastError();
    if (err != cudaSuccess) {
        fprintf(stderr, "CUDA Error after clearImage kernel launch: %s\\n", cudaGetErrorString(err));
    }
    // No explicit cudaDeviceSynchronize needed here, subsequent kernels will wait implicitly.
}

// advanceAnimation --
//
// Advance the simulation one time step.  Updates all circle positions
// and velocities
void
CudaRenderer::advanceAnimation() {
     // Use 1D blocks, 256 threads per block is generally good
    dim3 blockDim(256, 1);
    dim3 gridDim((numCircles + blockDim.x - 1) / blockDim.x);

    // Launch the appropriate animation kernel based on the scene
    if (sceneName == SNOWFLAKES) {
        kernelAdvanceSnowflake<<<gridDim, blockDim>>>();
    } else if (sceneName == BOUNCING_BALLS) {
        kernelAdvanceBouncingBalls<<<gridDim, blockDim>>>();
    } else if (sceneName == HYPNOSIS) {
        kernelAdvanceHypnosis<<<gridDim, blockDim>>>();
    } else if (sceneName == FIREWORKS) {
        kernelAdvanceFireWorks<<<gridDim, blockDim>>>();
    }

    // Check for errors after kernel launch
    cudaError_t err = cudaGetLastError();
    if (err != cudaSuccess) {
        fprintf(stderr, "CUDA Error after advanceAnimation kernel launch: %s\\n", cudaGetErrorString(err));
    }
    // No explicit cudaDeviceSynchronize needed here.
}


void
CudaRenderer::render() {
    // Set up a 2D grid of thread blocks. Each block handles a TILE_DIM x TILE_DIM pixel tile.
    // TILE_DIM is defined as 16, so blocks have 16x16 = 256 threads.
    dim3 blockDim(TILE_DIM, TILE_DIM);
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    // Launch the optimized tiled rendering kernel that uses shared memory
    kernelRenderCirclesTiledShared<<<gridDim, blockDim>>>();

    // Check for errors immediately after kernel launch (catches launch configuration errors)
    cudaError_t err = cudaGetLastError();
    if (err != cudaSuccess) {
        fprintf(stderr, "CUDA Error after render kernel launch: %s\\n", cudaGetErrorString(err));
    }

    // Synchronize after rendering to ensure the kernel is fully complete
    // before the CPU tries to copy the image data back in getImage().
    // Also catches any asynchronous errors that occurred during kernel execution.
    cudaCheckError(cudaDeviceSynchronize());
}
