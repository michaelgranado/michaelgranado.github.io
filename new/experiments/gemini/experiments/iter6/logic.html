proposed solution

Implement a new CUDA kernel, kernelRenderCirclesShared, that utilizes a tile-based approach similar to the previous kernelRenderCirclesTiled, but significantly optimizes memory access patterns by leveraging shared memory.

The core idea is:

  1. Assign each thread block to a tile of pixels (e.g., 16x16).
  2. Instead of each thread iterating through all potentially relevant circles individually and reading from global memory each time, the threads within a block will cooperate to load chunks of circle data (position, radius, color) into shared memory.
  3. The outer loop iterates through the circles in chunks (e.g., chunks of size equal to the block dimension, 256).
  4. Inside the loop, each thread loads one circle's data for the current chunk into shared memory arrays. A __syncthreads() barrier ensures all data is loaded before proceeding.
  5. Each thread then iterates through the chunk of circles residing in shared memory.
  6. For each circle in shared memory, the thread performs the necessary checks (conservative tile culling followed by precise pixel coverage) using the fast shared memory access.
  7. If a pixel is covered, the thread blends the circle's contribution into a local register variable (accumulatedColor).
  8. After processing all chunks, each thread performs a single write of its final accumulatedColor to global memory for its assigned pixel.
This approach maintains the pixel-centric assignment (one thread per pixel) and processes circles in their original input order, thus preserving the atomicity and ordering requirements. The performance improvement comes from drastically reducing global memory reads for circle data, replacing them with much faster shared memory reads.

solution reasoning

The previous implementation (kernelRenderCirclesTiled) suffered from a performance bottleneck because every thread within a block independently iterated through all circles potentially overlapping the block's tile. While the tile culling reduced the number of circles considered compared to iterating through *all* circles, it still resulted in significant redundant computation and, more importantly, redundant global memory accesses. For a given circle overlapping the tile, all threads in the block (e.g., 256) would read that circle's position, radius, and potentially color from global memory.

The proposed solution directly addresses this memory bottleneck. By loading chunks of circle data into shared memory:

  1. Reduced Global Memory Bandwidth: Circle data (position, radius, color) for a chunk is read from global memory only once per block, cooperatively by the threads, instead of once per thread. This dramatically reduces the demand on global memory bandwidth, which is often a limiting factor in GPU performance.
  2. Faster Data Access: Once loaded, threads access the circle data from shared memory, which is significantly faster (lower latency, higher bandwidth) than global memory.
  3. Preserved Correctness:
    • Order: The kernel processes circles sequentially chunk by chunk, and within each chunk, threads iterate from the beginning to the end of the chunk (indices 0 to `blockSize-1`). Since all threads process the same chunk before moving to the next, the global order of circle processing (0, 1, ..., numCircles-1) relative to any single pixel is maintained.
    • Atomicity: Each pixel is still exclusively handled by one thread. Color blending occurs in thread-local registers, and there is only one final write per pixel to the global image buffer. This avoids race conditions.
  4. Computational Efficiency: While threads still perform the `shadePixel` logic for circles that overlap the tile but not their specific pixel, the data required for this check now comes from fast shared memory, reducing the overhead compared to fetching from global memory each time.
This shared memory optimization targets the primary scaling issue of the previous tiled approach, allowing the renderer to handle scenes with large numbers of circles much more efficiently while maintaining the required correctness invariants.

    int imageX = blockIdx.x * blockDim.x + threadIdx.x;

    int height = cuConstRendererParams.imageHeight;

// kernelAdvanceFireWorks, kernelAdvanceHypnosis, kernelAdvanceBouncingBalls, kernelAdvanceSnowflake
// ... (These kernels remain the same as in the provided correct_unoptimized_code) ...
// kernelAdvanceFireWorks
//
// Update the position of the fireworks (if circle is firework)
__global__ void kernelAdvanceFireWorks() {
    const float dt = 1.f / 60.f;
    const float pi = 3.14159;
    const float maxDist = 0.25f;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;
    float* radius = cuConstRendererParams.radius;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;

    if (0 <= index && index < NUM_FIREWORKS) { // firework center; no update
        return;
    }

    // determine the fire-work center/spark indices
    int fIdx = (index - NUM_FIREWORKS) / NUM_SPARKS;
    int sfIdx = (index - NUM_FIREWORKS) % NUM_SPARKS;

    int index3i = 3 * fIdx;
    int sIdx = NUM_FIREWORKS + fIdx * NUM_SPARKS + sfIdx;
    int index3j = 3 * sIdx;

    float cx = position[index3i];
    float cy = position[index3i+1];

    // update position
    position[index3j] += velocity[index3j] * dt;
    position[index3j+1] += velocity[index3j+1] * dt;

    // fire-work sparks
    float sx = position[index3j];
    float sy = position[index3j+1];

    // compute vector from firework-spark
    float cxsx = sx - cx;
    float cysy = sy - cy;

    // compute distance from fire-work
    float dist = sqrt(cxsx * cxsx + cysy * cysy);
    if (dist > maxDist) { // restore to starting position
        // random starting position on fire-work's rim
        float angle = (sfIdx * 2 * pi)/NUM_SPARKS;
        float sinA = sin(angle);
        float cosA = cos(angle);
        float x = cosA * radius[fIdx];
        float y = sinA * radius[fIdx];

        position[index3j] = position[index3i] + x;
        position[index3j+1] = position[index3i+1] + y;
        position[index3j+2] = 0.0f;

        // travel scaled unit length
        velocity[index3j] = cosA/5.0;
        velocity[index3j+1] = sinA/5.0;
        velocity[index3j+2] = 0.0f;
    }
}

// kernelAdvanceBouncingBalls
//
// Update the positino of the balls
__global__ void kernelAdvanceBouncingBalls() {
    const float dt = 1.f / 60.f;
    const float kGravity = -2.8f; // sorry Newton
    const float kDragCoeff = -0.8f;
    const float epsilon = 0.001f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;

    int index3 = 3 * index;
    // reverse velocity if center position < 0
    float oldVelocity = velocity[index3+1];
    float oldPosition = position[index3+1];

    if (oldVelocity == 0.f && oldPosition == 0.f) { // stop-condition
        return;
    }

    if (position[index3+1] < 0 && oldVelocity < 0.f) { // bounce ball
        velocity[index3+1] *= kDragCoeff;
    }

    // update velocity: v = u + at (only along y-axis)
    velocity[index3+1] += kGravity * dt;

    // update positions (only along y-axis)
    position[index3+1] += velocity[index3+1] * dt;

    if (fabsf(velocity[index3+1] - oldVelocity) < epsilon
        && oldPosition < 0.0f
        && fabsf(position[index3+1]-oldPosition) < epsilon) { // stop ball
        velocity[index3+1] = 0.f;
        position[index3+1] = 0.f;
    }
}

// kernelAdvanceSnowflake -- (CUDA device code)
//
// move the snowflake animation forward one time step.  Updates circle
// positions and velocities.
__global__ void kernelAdvanceSnowflake() {

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    const float dt = 1.f / 60.f;
    const float kGravity = -1.8f; // sorry Newton
    const float kDragCoeff = 2.f;

    int index3 = 3 * index;

    float* positionPtr = &cuConstRendererParams.position[index3];
    float* velocityPtr = &cuConstRendererParams.velocity[index3];

    // loads from global memory
    float3 position = *((float3*)positionPtr);
    float3 velocity = *((float3*)velocityPtr);

    // hack to make farther circles move more slowly
    float forceScaling = fminf(fmaxf(1.f - position.z, .1f), 1.f); // clamp

    // add some noise to the motion
    float3 noiseInput;
    noiseInput.x = 10.f * position.x;
    noiseInput.y = 10.f * position.y;
    noiseInput.z = 255.f * position.z;
    float2 noiseForce = cudaVec2CellNoise(noiseInput, index);
    noiseForce.x *= 7.5f;
    noiseForce.y *= 5.f;

    // drag
    float2 dragForce;
    dragForce.x = -1.f * kDragCoeff * velocity.x;
    dragForce.y = -1.f * kDragCoeff * velocity.y;

    // update positions
    position.x += velocity.x * dt;
    position.y += velocity.y * dt;

    // update velocities
    velocity.x += forceScaling * (noiseForce.x + dragForce.y) * dt;
    velocity.y += forceScaling * (kGravity + noiseForce.y + dragForce.y) * dt;

    float radius = cuConstRendererParams.radius[index];

    // if the snowflake has moved off screen, reset its position
    if ( (position.y + radius < 0.f) ||
         (position.x + radius) < -0.f ||
         (position.x - radius) > 1.f)
    {
        noiseInput.x = 255.f * position.x;
        noiseInput.y = 255.f * position.y;
        noiseInput.z = 255.f * position.z;
        noiseForce = cudaVec2CellNoise(noiseInput, index);

        position.x = .5f + .5f * noiseForce.x;
        position.y = 1.35f + radius;

        velocity.x = 2.f * noiseForce.y;
        velocity.y = 0.f;
    }

    // store updated positions and velocities to global memory
    *((float3*)positionPtr) = position;
    *((float3*)velocityPtr) = velocity;
}


// shadePixelOptimized -- (CUDA device code)
//
// Optimized version of shadePixel. Given a pixel center and circle data
// (potentially from shared memory), determines the contribution to the
// pixel from the circle and blends it into the pixelValue accumulator.
// Takes pre-fetched circle data (position, radius, color) as arguments.
__device__ __inline__ void
shadePixelOptimized(int circleIndex, // Still needed for global color lookup in non-snowflake mode if not using shared color
                    float2 pixelCenter,
                    float3 p_shared,      // Circle position from shared mem
                    float rad_shared,     // Circle radius from shared mem
                    float3 color_shared,  // Circle color from shared mem (used for non-snowflake)
                    float4& pixelValue) { // Accumulator (local register)

    float diffX = p_shared.x - pixelCenter.x;
    float diffY = p_shared.y - pixelCenter.y;
    float pixelDistSq = diffX * diffX + diffY * diffY; // Use squared distance

    float maxDistSq = rad_shared * rad_shared;

    // Early exit if pixel center is outside the circle's radius squared
    if (pixelDistSq > maxDistSq)
        return;

    // Pixel is inside the circle, compute shading
    float3 rgb;
    float alpha;

    // Shading logic depends on the scene
    if (cuConstRendererParams.sceneName == SNOWFLAKES ||
        cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {

        const float kCircleMaxAlpha = .5f;
        const float falloffScale = 4.f;

        // Calculate normalized distance only if inside the circle
        float pixelDist = sqrtf(pixelDistSq); // Compute sqrt only when needed
        float normPixelDist = pixelDist / rad_shared; // Avoid division by zero if rad_shared can be 0

        // Lookup color from ramp based on normalized distance
        rgb = lookupColor(normPixelDist); // Uses global constant memory __constant__ cuConstColorRamp

        // Calculate alpha based on depth (z) and distance
        float maxAlpha = .6f + .4f * (1.f - p_shared.z); // Use z from shared position
        maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f); // Clamp and scale
        alpha = maxAlpha * expf(-1.f * falloffScale * normPixelDist * normPixelDist);

    } else {
        // Simple case: use the color loaded into shared memory
        rgb = color_shared;
        alpha = .5f; // Constant alpha for non-snowflake scenes
    }

    // Perform alpha blending (standard "over" operation)
    // result = foreground * alpha + background * (1 - alpha)
    float oneMinusAlpha = 1.f - alpha;
    // Blend RGB
    pixelValue.x = alpha * rgb.x + oneMinusAlpha * pixelValue.x;
    pixelValue.y = alpha * rgb.y + oneMinusAlpha * pixelValue.y;
    pixelValue.z = alpha * rgb.z + oneMinusAlpha * pixelValue.z;

    // Blend Alpha (using the original assignment's logic for consistency, though likely incorrect for true alpha blending)
    // A correct over operator would be: pixelValue.w = alpha + oneMinusAlpha * pixelValue.w;
    // But the original code did simple addition:
    pixelValue.w = alpha + pixelValue.w;
}


// kernelRenderCirclesShared -- (CUDA device code)
//
// Renders circles using a tile-based approach with shared memory optimization.
// Each thread block handles a tile of pixels (TILE_SIZE_X * TILE_SIZE_Y).
// Threads within a block cooperate to load circle data into shared memory in chunks.
__global__ void kernelRenderCirclesShared() {

    // Shared memory for caching circle data within the block
    __shared__ float3 s_positions[BLOCK_SIZE];
    __shared__ float  s_radii[BLOCK_SIZE];
    __shared__ float3 s_colors[BLOCK_SIZE]; // Store color in shared mem for non-snowflake scenes

    // Calculate pixel coordinates for this thread
    int pixelX = blockIdx.x * TILE_SIZE_X + threadIdx.x;
    int pixelY = blockIdx.y * TILE_SIZE_Y + threadIdx.y;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Check if the pixel is within image bounds
    if (pixelX >= imageWidth || pixelY >= imageHeight)
        return;

    // Calculate linear thread ID within the block (0 to BLOCK_SIZE-1)
    // Important: Use row-major ordering for potential coalescing during shared memory load
    int tid = threadIdx.y * TILE_SIZE_X + threadIdx.x;

    // Calculate normalized coordinates for the pixel center
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float2 pixelCenterNorm = make_float2(invWidth * (static_cast<float>(pixelX) + 0.5f),
                                         invHeight * (static_cast<float>(pixelY) + 0.5f));

    // Calculate the normalized boundaries of this thread's tile (block) for culling
    // These are the same for all threads in the block
    float tileL = invWidth * (blockIdx.x * TILE_SIZE_X);
    float tileR = invWidth * ((blockIdx.x + 1) * TILE_SIZE_X);
    float tileB = invHeight * (blockIdx.y * TILE_SIZE_Y);
    float tileT = invHeight * ((blockIdx.y + 1) * TILE_SIZE_Y);

    // Get pointer to this pixel's data in global memory
    int pixelOffset = 4 * (pixelY * imageWidth + pixelX);
    float4* imgPtrGlobal = (float4*)(&cuConstRendererParams.imageData[pixelOffset]);

    // Initialize accumulated color in register, reading the background color
    float4 accumulatedColor = *imgPtrGlobal;

    // Determine if color needs to be loaded into shared memory (only for non-snowflake)
    bool loadSharedColor = (cuConstRendererParams.sceneName != SNOWFLAKES &&
                            cuConstRendererParams.sceneName != SNOWFLAKES_SINGLE_FRAME);

    // --- Main Loop: Iterate through circles in chunks ---
    int numCircles = cuConstRendererParams.numCircles;
    for (int chunkBase = 0; chunkBase < numCircles; chunkBase += BLOCK_SIZE) {

        // --- Step 1: Cooperatively load circle chunk into Shared Memory ---
        int circleIdxGlobal = chunkBase + tid; // Global index of the circle this thread will load

        // Boundary check: Only load if the circle index is valid
        if (circleIdxGlobal < numCircles) {
            // Load position (float3) and radius (float)
            s_positions[tid] = *(float3*)&(cuConstRendererParams.position[3 * circleIdxGlobal]);
            s_radii[tid] = cuConstRendererParams.radius[circleIdxGlobal];

            // Load color (float3) only if needed for this scene type
            if (loadSharedColor) {
                s_colors[tid] = *(float3*)&(cuConstRendererParams.color[3 * circleIdxGlobal]);
            }
        }

        // Wait for all threads in the block to finish loading into shared memory
        __syncthreads();

        // --- Step 2: Process circles from Shared Memory ---
        // Iterate through the circles currently loaded in shared memory (up to BLOCK_SIZE)
        int numCirclesInChunk = min(BLOCK_SIZE, numCircles - chunkBase);

        for (int i = 0; i < numCirclesInChunk; ++i) {
            // Get circle data from shared memory
            float3 p_shared = s_positions[i];
            float rad_shared = s_radii[i];
            // Get color from shared mem if it was loaded, otherwise it's unused by shadePixelOptimized
            float3 color_shared = loadSharedColor ? s_colors[i] : make_float3(0.f, 0.f, 0.f); // Dummy color if not loaded

            // Global index of the circle being processed (needed for potential non-shared lookups)
            int currentCircleIdxGlobal = chunkBase + i;

            // *** Optimization: Tile Culling Check ***
            // Use the conservative box test: If the circle (from shared mem)
            // doesn't overlap the tile's bounding box, skip detailed checks for this thread.
            // This check uses data efficiently fetched from shared memory.
            if (circleInBoxConservative(p_shared.x, p_shared.y, rad_shared, tileL, tileR, tileT, tileB)) {

                // *** Precise Pixel Shading ***
                // If the circle might overlap the tile, perform the precise check and shading
                // using data primarily from shared memory.
                shadePixelOptimized(currentCircleIdxGlobal, pixelCenterNorm, p_shared, rad_shared, color_shared, accumulatedColor);
            }
        } // End loop over circles in shared memory chunk

        // Wait for all threads to finish processing the current chunk
        // Ensures shared memory isn't overwritten by the next chunk load prematurely
        __syncthreads();

    } // End loop over chunks

    // --- Step 3: Write final accumulated color to global memory ---
    // Each thread writes its final computed pixel color once.
    *imgPtrGlobal = accumulatedColor;
}

CudaRenderer::CudaRenderer() {
    image = NULL;

    numCircles = 0;
    position = NULL;
    velocity = NULL;
    color = NULL;
    radius = NULL;

    cudaDeviceImageData = NULL;

CudaRenderer::~CudaRenderer() {

    if (image) {
        delete image;
    }

    // Free host memory
    if (position) {
        delete [] position;
        delete [] velocity;
        delete [] color;
        delete [] radius;
    }

    // Free device memory
    if (cudaDevicePosition) {
        cudaFree(cudaDevicePosition);
        cudaFree(cudaDeviceVelocity);
        cudaFree(cudaDeviceColor);
        cudaFree(cudaDeviceRadius);
        cudaFree(cudaDeviceImageData);
    }
}

const Image* CudaRenderer::getImage() {
    // Copy rendered image data from device to host
    cudaCheckError(cudaMemcpy(image->data,
                              cudaDeviceImageData,
                              sizeof(float) * 4 * image->width * image->height,
                              cudaMemcpyDeviceToHost));
    return image;
}

    int deviceCount = 0;
    cudaCheckError(cudaGetDeviceCount(&deviceCount));

    printf("---------------------------------------------------------\n");
    printf("Initializing CUDA for CudaRenderer\n");
    printf("Found %d CUDA devices\n", deviceCount);

    for (int i=0; i<deviceCount; i++) {
        cudaDeviceProp deviceProps;
        cudaCheckError(cudaGetDeviceProperties(&deviceProps, i));
        printf("Device %d: %s\n", i, deviceProps.name);
        printf("   SMs:        %d\n", deviceProps.multiProcessorCount);
        printf("   Global mem: %.0f MB\n", static_cast<float>(deviceProps.totalGlobalMem) / (1024 * 1024));
        printf("   CUDA Cap:   %d.%d\n", deviceProps.major, deviceProps.minor);
        printf("   Shared/blk: %zu bytes\n", deviceProps.sharedMemPerBlock); // Print shared mem info
    }
    printf("---------------------------------------------------------\n");

    // Allocate memory on the CUDA device
    cudaCheckError(cudaMalloc(&cudaDevicePosition, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceVelocity, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceColor, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceRadius, sizeof(float) * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceImageData, sizeof(float) * 4 * image->width * image->height));

    // Copy scene data from host to device
    cudaCheckError(cudaMemcpy(cudaDevicePosition, position, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceVelocity, velocity, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceColor, color, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceRadius, radius, sizeof(float) * numCircles, cudaMemcpyHostToDevice));

    // Setup constant memory parameters
    GlobalConstants params;
    params.sceneName = sceneName;
    params.numCircles = numCircles;
    params.imageWidth = image->width;
    params.imageHeight = image->height;
    params.position = cudaDevicePosition;
    params.velocity = cudaDeviceVelocity;
    params.color = cudaDeviceColor;
    params.radius = cudaDeviceRadius;
    params.imageData = cudaDeviceImageData;

    cudaCheckError(cudaMemcpyToSymbol(cuConstRendererParams, &params, sizeof(GlobalConstants)));

    // Copy noise tables to constant memory
    int* permX;
    int* permY;
    float* value1D;
    getNoiseTables(&permX, &permY, &value1D);
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseXPermutationTable, permX, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseYPermutationTable, permY, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoise1DValueTable, value1D, sizeof(float) * 256));

    // Copy color ramp table to constant memory
    float lookupTable[COLOR_MAP_SIZE][3] = {
        {1.f, 1.f, 1.f},
        {1.f, 1.f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, .9f, 1.f},
        {.8f, 0.8f, 1.f},
    };
    cudaCheckError(cudaMemcpyToSymbol(cuConstColorRamp, lookupTable, sizeof(float) * 3 * COLOR_MAP_SIZE));

    printf("CUDA setup complete.\n"); // Debug print
}

void CudaRenderer::allocOutputImage(int width, int height) {
    if (image)
        delete image;
    image = new Image(width, height);
    printf("Allocated output image %dx%d\n", width, height); // Debug print
}

void CudaRenderer::clearImage() {
    // Use 16x16 blocks for clearing as well
    dim3 blockDim(TILE_SIZE_X, TILE_SIZE_Y);
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
        kernelClearImageSnowflake<<<gridDim, blockDim>>>();
    } else {
        // Clear with opaque white background (alpha=1)
        kernelClearImage<<<gridDim, blockDim>>>(1.f, 1.f, 1.f, 1.f);
    }
    // Check for errors after kernel launch (useful for debugging)
    cudaCheckError(cudaGetLastError());
}

void CudaRenderer::advanceAnimation() {
    // Use 1D blocks for animation kernels (simpler)
    dim3 blockDim(256, 1); // Can tune this block size
    dim3 gridDim((numCircles + blockDim.x - 1) / blockDim.x);

    // Launch appropriate animation kernel based on scene
    if (sceneName == SNOWFLAKES) {
        kernelAdvanceSnowflake<<<gridDim, blockDim>>>();
    } else if (sceneName == BOUNCING_BALLS) {
        kernelAdvanceBouncingBalls<<<gridDim, blockDim>>>();
    } else if (sceneName == HYPNOSIS) {
        kernelAdvanceHypnosis<<<gridDim, blockDim>>>();
    } else if (sceneName == FIREWORKS) {
        kernelAdvanceFireWorks<<<gridDim, blockDim>>>();
    }
    // Check for errors after kernel launch
    cudaCheckError(cudaGetLastError());
}


void CudaRenderer::render() {
    // Setup grid and block dimensions for the shared memory kernel
    dim3 blockDim(TILE_SIZE_X, TILE_SIZE_Y); // e.g., 16x16 = 256 threads
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    // Launch the optimized kernel using shared memory
    kernelRenderCirclesShared<<<gridDim, blockDim>>>();

    // Check for kernel launch errors
    cudaCheckError(cudaGetLastError());

    // Synchronize after rendering to ensure completion before potential host copy (getImage)
    // and for accurate timing.
    cudaCheckError(cudaDeviceSynchronize());
}
