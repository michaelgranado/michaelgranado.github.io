You are a Teaching Assistant for a Parallel Computing course at Stanford University and you are trying to complete a student's programming assignment. You will be given the programming task instructions, correct but unoptimized code, the descriptions of the 8 test cases we will use to evaluate your code, and the results from the test harness used to evaluate your code. In addition to this, you are also given supplementary code files which detail subroutines mentioned in the instructions. Here is how you should interpret the results from the test harness:

    1. The first line of each test case tells you whether or not you passed the correctness check.
    2. The second line of each test case tells you the speed at which your solution ran.
    3. The final line of each test case tells you the speed at which the reference solution ran.

remedy reasoning: Describe the rationale you had for coming up with this solution. Also, please answer the following questions: 1) Why do you think this solution will fix the problem? 2) What do you expect the program results to be when after this change is implemented?
code: Generated code that incorporates your proposed remedy. Output the new code in codeblocks. Please generate real code, NOT pseudocode, make sure the code compiles and is fully functional. Do not output testing code.
