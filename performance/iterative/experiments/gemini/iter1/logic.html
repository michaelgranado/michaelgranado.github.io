CUDA Renderer Optimization Strategy

CUDA Renderer Optimization Strategy

strategy:

  1. Implement Tile-Based Rendering: Divide the image into 2D tiles (e.g., 16x16 pixels). Assign each tile to a CUDA thread block.
  2. Per-Tile Pixel Processing: Each thread within a block will be responsible for computing the final color of one pixel within that tile.
  3. Iterate Through Circles in Chunks: Instead of each pixel thread iterating through all circles individually, the entire thread block will collectively iterate through the circles in chunks.
  4. Load Circle Data to Shared Memory: For each chunk of circles, load the essential data (position, radius) into shared memory. This aims to reduce global memory bandwidth usage during the pixel processing phase for that chunk, assuming threads within the block access the same circle data frequently. Color data will be loaded from global memory only when a pixel is confirmed to be covered by a circle.
  5. Conservative Tile Culling: Before performing the expensive per-pixel distance check for a circle, perform a cheaper conservative check (circleInBoxConservative) to see if the circle loaded into shared memory can possibly intersect the current tile being processed by the block. If it cannot, all threads in the block can skip the per-pixel check for that circle.
  6. Per-Pixel Circle Test and Blend: If a circle passes the tile culling test, each thread proceeds to check if its specific pixel center lies within that circle. If it does, the thread loads the circle's color, calculates its contribution, and blends it into a local accumulator variable (stored in registers).
  7. Maintain Order: The iteration through circle chunks and circles within chunks must strictly follow the original input order (index 0, 1, 2, ...). Blending into the local register accumulator respects this order implicitly for each pixel.
  8. Final Write: After iterating through all circle chunks, each thread writes its final accumulated pixel color from its register variable to the global image buffer.

reasoning:

The provided correct code (`kernelRenderPixelCentric`) assigns one thread per pixel and iterates through all circles for each pixel. This guarantees correctness (atomicity and order) because each pixel's computation is isolated to a single thread, processing circles sequentially. However, its performance is poor due to massive computational redundancy and inefficient memory access patterns.

  • Problem 1: Redundant Computations: Every pixel thread checks against every single circle, even those geometrically impossible to overlap the pixel. The tile-based approach mitigates this by introducing a coarse-grained culling step: if a circle doesn't overlap the tile, none of the pixels within that tile need to check it further. The circleInBoxConservative test is used for this tile-level culling as it's faster than a precise test.
  • Problem 2: Memory Bandwidth/Latency: In the pixel-centric approach, adjacent threads (processing adjacent pixels) might access data for vastly different circles in the inner loop, leading to uncoalesced global memory reads for circle positions, radii, and colors. Loading chunks of circle data (primarily position and radius needed for intersection tests) into shared memory allows threads within the block to potentially reuse this data from the faster shared memory. While the initial load from global to shared memory still occurs, subsequent accesses within the inner loop over the chunk might benefit. The more expensive color data is only loaded from global memory when a pixel is confirmed to be covered, reducing unnecessary loads.
  • Problem 3: Lack of Circle Parallelism: The pixel-centric approach only parallelizes across pixels. The proposed tile-based approach still parallelizes across pixels (within tiles) but structures the computation differently. While it doesn't parallelize the *blending* of different circles onto the same pixel (which would violate ordering), it improves efficiency by reducing redundant checks and optimizing memory access.
  • Maintaining Correctness: The core correctness logic is preserved. Atomicity is maintained because each pixel is still exclusively handled by a single thread from start to finish (initial read, accumulation in registers, final write). Order is maintained because the loops iterating through circle chunks and circles within those chunks strictly follow the original input circle order (0 to `numCircles` - 1). Blending operations within each thread's accumulator happen in this correct sequence.
  • Implementation Choice: This strategy is chosen over more complex methods like explicit fragment generation and sorting because it builds incrementally on the concept of the correct pixel-centric kernel, adding spatial culling and shared memory optimizations. It avoids the potentially very large intermediate buffers and expensive sorting required by fragment-based methods, which might be problematic for scenes with millions of circles. The complexity lies in managing shared memory loading and synchronization (`__syncthreads`) correctly.

__global__ void kernelClearImageSnowflake() {

    int imageX = blockIdx.x * blockDim.x + threadIdx.x;
    int imageY = blockIdx.y * blockDim.y + threadIdx.y;

    int width = cuConstRendererParams.imageWidth;
    int height = cuConstRendererParams.imageHeight;

    if (imageX >= width || imageY >= height)
        return;

    int offset = 4 * (imageY * width + imageX);
    float shade = .4f + .45f * static_cast<float>(height-imageY) / height;
    float4 value = make_float4(shade, shade, shade, 1.f); // NOTE: Alpha is 1 for background
    *(float4*)(&cuConstRendererParams.imageData[offset]) = value;
}

// Animation Kernels (kernelAdvanceFireWorks, kernelAdvanceHypnosis, kernelAdvanceBouncingBalls, kernelAdvanceSnowflake)
// (Same as provided - No changes needed for animation logic)
__global__ void kernelAdvanceFireWorks() {
    const float dt = 1.f / 60.f;
    const float pi = 3.14159;
    const float maxDist = 0.25f;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;
    float* radius = cuConstRendererParams.radius;

    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;
    if (0 <= index && index < NUM_FIREWORKS) { // firework center; no update
        return;
    }
    // determine the fire-work center/spark indices
    int fIdx = (index - NUM_FIREWORKS) / NUM_SPARKS;
    int sfIdx = (index - NUM_FIREWORKS) % NUM_SPARKS;

    int index3i = 3 * fIdx;
    int sIdx = NUM_FIREWORKS + fIdx * NUM_SPARKS + sfIdx;
    int index3j = 3 * sIdx;

    float cx = position[index3i];
    float cy = position[index3i+1];

    // update position
    position[index3j] += velocity[index3j] * dt;
    position[index3j+1] += velocity[index3j+1] * dt;

    // fire-work sparks
    float sx = position[index3j];
    float sy = position[index3j+1];

    // compute vector from firework-spark
    float cxsx = sx - cx;
    float cysy = sy - cy;

    // compute distance from fire-work
    float dist = sqrt(cxsx * cxsx + cysy * cysy);
    if (dist > maxDist) { // restore to starting position
        // random starting position on fire-work's rim
        float angle = (sfIdx * 2 * pi)/NUM_SPARKS;
        float sinA = sin(angle);
        float cosA = cos(angle);
        float x = cosA * radius[fIdx];
        float y = sinA * radius[fIdx];

        position[index3j] = position[index3i] + x;
        position[index3j+1] = position[index3i+1] + y;
        position[index3j+2] = 0.0f;

        // travel scaled unit length
        velocity[index3j] = cosA/5.0;
        velocity[index3j+1] = sinA/5.0;
        velocity[index3j+2] = 0.0f;
    }
}

__global__ void kernelAdvanceHypnosis() {
    int index = blockIdx.x * blockDim.x + threadIdx.x;
    if (index >= cuConstRendererParams.numCircles)
        return;

    float* radius = cuConstRendererParams.radius;

    float cutOff = 0.5f;
    // place circle back in center after reaching threshold radisus
    if (radius[index] > cutOff) {
        radius[index] = 0.02f;
    } else {
        radius[index] += 0.01f;
    }
}


__global__ void kernelAdvanceBouncingBalls() {
    const float dt = 1.f / 60.f;
    const float kGravity = -2.8f; // sorry Newton
    const float kDragCoeff = -0.8f;
    const float epsilon = 0.001f;

    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    float* velocity = cuConstRendererParams.velocity;
    float* position = cuConstRendererParams.position;

    int index3 = 3 * index;
    // reverse velocity if center position < 0
    float oldVelocity = velocity[index3+1];
    float oldPosition = position[index3+1];

    if (oldVelocity == 0.f && oldPosition == 0.f) { // stop-condition
        return;
    }

    if (position[index3+1] < 0 && oldVelocity < 0.f) { // bounce ball
        velocity[index3+1] *= kDragCoeff;
    }

    // update velocity: v = u + at (only along y-axis)
    velocity[index3+1] += kGravity * dt;

    // update positions (only along y-axis)
    position[index3+1] += velocity[index3+1] * dt;

    if (fabsf(velocity[index3+1] - oldVelocity) < epsilon
        && oldPosition < 0.0f
        && fabsf(position[index3+1]-oldPosition) < epsilon) { // stop ball
        velocity[index3+1] = 0.f;
        position[index3+1] = 0.f;
    }
}


__global__ void kernelAdvanceSnowflake() {
    int index = blockIdx.x * blockDim.x + threadIdx.x;

    if (index >= cuConstRendererParams.numCircles)
        return;

    const float dt = 1.f / 60.f;
    const float kGravity = -1.8f; // sorry Newton
    const float kDragCoeff = 2.f;

    int index3 = 3 * index;

    float* positionPtr = &cuConstRendererParams.position[index3];
    float* velocityPtr = &cuConstRendererParams.velocity[index3];

    // loads from global memory
    float3 position = *((float3*)positionPtr);
    float3 velocity = *((float3*)velocityPtr);

    // hack to make farther circles move more slowly, giving the
    // illusion of parallax
    float forceScaling = fmin(fmax(1.f - position.z, .1f), 1.f); // clamp

    // add some noise to the motion to make the snow flutter
    float3 noiseInput;
    noiseInput.x = 10.f * position.x;
    noiseInput.y = 10.f * position.y;
    noiseInput.z = 255.f * position.z;
    float2 noiseForce = cudaVec2CellNoise(noiseInput, index);
    noiseForce.x *= 7.5f;
    noiseForce.y *= 5.f;

    // drag
    float2 dragForce;
    dragForce.x = -1.f * kDragCoeff * velocity.x;
    dragForce.y = -1.f * kDragCoeff * velocity.y;

    // update positions
    position.x += velocity.x * dt;
    position.y += velocity.y * dt;

    // update velocities
    velocity.x += forceScaling * (noiseForce.x + dragForce.y) * dt;
    velocity.y += forceScaling * (kGravity + noiseForce.y + dragForce.y) * dt;

    float radius = cuConstRendererParams.radius[index];

    // if the snowflake has moved off the left, right or bottom of
    // the screen, place it back at the top and give it a
    // pseudorandom x position and velocity.
    if ( (position.y + radius < 0.f) ||
         (position.x + radius) < -0.f ||
         (position.x - radius) > 1.f)
    {
        noiseInput.x = 255.f * position.x;
        noiseInput.y = 255.f * position.y;
        noiseInput.z = 255.f * position.z;
        noiseForce = cudaVec2CellNoise(noiseInput, index);

        position.x = .5f + .5f * noiseForce.x;
        position.y = 1.35f + radius;

        // restart from 0 vertical velocity.  Choose a
        // pseudo-random horizontal velocity.
        velocity.x = 2.f * noiseForce.y;
        velocity.y = 0.f;
    }

    // store updated positions and velocities to global memory
    *((float3*)positionPtr) = position;
    *((float3*)velocityPtr) = velocity;
}

// ** NEW OPTIMIZED KERNEL **
// kernelRenderTileCentric -- (CUDA device code)
//
// Renders circles tile by tile. Each block handles one tile.
// Circles are processed in chunks, loaded into shared memory.
// Tile culling and per-pixel checks are performed.
// Order and atomicity are maintained.
// *********************************************************************************
__global__ void kernelRenderTileCentric() {

    // Shared memory for circle positions (x,y,z) and radii for one chunk
    // Size: CIRCLE_CHUNK_SIZE * (3 floats for pos + 1 float for radius)
    __shared__ float s_circle_pos_rad[CIRCLE_CHUNK_SIZE * 4];

    // Calculate this thread's pixel coordinates (global image coordinates)
    int tileX = blockIdx.x;
    int tileY = blockIdx.y;
    int threadX = threadIdx.x;
    int threadY = threadIdx.y;

    int globalPixelX = tileX * TILE_DIM_X + threadX;
    int globalPixelY = tileY * TILE_DIM_Y + threadY;

    int imageWidth = cuConstRendererParams.imageWidth;
    int imageHeight = cuConstRendererParams.imageHeight;

    // Calculate normalized pixel center coordinates [0, 1]
    float invWidth = 1.f / imageWidth;
    float invHeight = 1.f / imageHeight;
    float pixelCenterX = invWidth * (static_cast<float>(globalPixelX) + 0.5f);
    float pixelCenterY = invHeight * (static_cast<float>(pixelY) + 0.5f);
    float2 pixelCenterNorm = make_float2(pixelCenterX, pixelCenterY);

    // Calculate tile boundaries in normalized coordinates
    float tileL = invWidth * static_cast<float>(tileX * TILE_DIM_X);
    float tileR = invWidth * static_cast<float>((tileX + 1) * TILE_DIM_X);
    float tileB = invHeight * static_cast<float>(tileY * TILE_DIM_Y);
    float tileT = invHeight * static_cast<float>((tileY + 1) * TILE_DIM_Y);

    // Local accumulator for the pixel color this thread is responsible for
    float4 accumulatedColor = make_float4(1.f, 1.f, 1.f, 1.f); // Default background

    // Check if pixel is within image bounds before reading initial color
    if (globalPixelX < imageWidth && globalPixelY < imageHeight) {
        int pixelOffset = 4 * (globalPixelY * imageWidth + globalPixelX);
        accumulatedColor = *(float4*)(&cuConstRendererParams.imageData[pixelOffset]);
    }

    // Calculate linearized thread index within the block
    int tid = threadY * TILE_DIM_X + threadX;
    int threadsPerBlock = TILE_DIM_X * TILE_DIM_Y; // Should be <= 1024

    // Iterate through circles in chunks
    for (int chunkBase = 0; chunkBase < cuConstRendererParams.numCircles; chunkBase += CIRCLE_CHUNK_SIZE) {

        // Cooperatively load circle chunk data (pos + radius) into shared memory
        int circlesInChunk = min(CIRCLE_CHUNK_SIZE, cuConstRendererParams.numCircles - chunkBase);

        // Each thread loads one circle's data if it exists
        // Store pos (x,y,z) and radius together: [x0,y0,z0,r0, x1,y1,z1,r1, ...]
        if (tid < circlesInChunk) {
            int circleIndex = chunkBase + tid;
            int globalPosIndex = 3 * circleIndex;
            int sharedIndex = 4 * tid;

            // Load position (float3)
            float3 pos = *(float3*)(&cuConstRendererParams.position[globalPosIndex]);
            s_circle_pos_rad[sharedIndex]   = pos.x;
            s_circle_pos_rad[sharedIndex+1] = pos.y;
            s_circle_pos_rad[sharedIndex+2] = pos.z;

            // Load radius (float)
            s_circle_pos_rad[sharedIndex+3] = cuConstRendererParams.radius[circleIndex];
        }

        // Wait for all threads in the block to finish loading before proceeding
        __syncthreads();

        // Check bounds: only process if this thread's pixel is inside the image
        if (globalPixelX < imageWidth && globalPixelY < imageHeight) {

            // Iterate through the circles currently loaded in shared memory
            for (int i = 0; i < circlesInChunk; ++i) {
                int circleIndex = chunkBase + i; // Original index of the circle
                int sharedIndex = 4 * i;

                // Read circle data from shared memory
                float circleX = s_circle_pos_rad[sharedIndex];
                float circleY = s_circle_pos_rad[sharedIndex+1];
                float circleZ = s_circle_pos_rad[sharedIndex+2]; // Needed for snow alpha/color
                float circleRad = s_circle_pos_rad[sharedIndex+3];

                // --- Tile Culling ---
                // Check if the circle potentially intersects this tile
                if (!circleInBoxConservative(circleX, circleY, circleRad, tileL, tileR, tileT, tileB)) {
                    continue; // Skip this circle if it cannot intersect the tile
                }

                // --- Per-Pixel Test ---
                // Check if the pixel center is inside this circle
                float diffX = circleX - pixelCenterNorm.x;
                float diffY = circleY - pixelCenterNorm.y;
                float distSq = diffX * diffX + diffY * diffY;
                float radSq = circleRad * circleRad;

                if (distSq <= radSq) {
                    // Pixel center is inside the circle, calculate color contribution and blend

                    float3 circleRgb;
                    float circleAlpha;

                    // Determine circle color and alpha based on scene type
                    if (cuConstRendererParams.sceneName == SNOWFLAKES || cuConstRendererParams.sceneName == SNOWFLAKES_SINGLE_FRAME) {
                        const float kCircleMaxAlpha = .5f;
                        const float falloffScale = 4.f;

                        float normPixelDist = sqrtf(distSq) / circleRad;
                        circleRgb = lookupColor(normPixelDist); // Uses lookupColor.cu_inl

                        float maxAlpha = .6f + .4f * (1.f - circleZ); // Use circle's Z for alpha modulation
                        maxAlpha = kCircleMaxAlpha * fmaxf(fminf(maxAlpha, 1.f), 0.f); // Clamp and scale
                        circleAlpha = maxAlpha * expf(-1.f * falloffScale * normPixelDist * normPixelDist);
                    } else {
                        // Simple case: fixed color per circle, fixed alpha
                        int index3_color = 3 * circleIndex;
                        circleRgb = *(float3*)&(cuConstRendererParams.color[index3_color]);
                        circleAlpha = .5f; // Default alpha for non-snowflake scenes
                    }

                    // Perform the blending operation using the "over" operator into the accumulator
                    // result = alpha * foreground + (1 - alpha) * background
                    float oneMinusAlpha = 1.f - circleAlpha;
                    accumulatedColor.x = circleAlpha * circleRgb.x + oneMinusAlpha * accumulatedColor.x;
                    accumulatedColor.y = circleAlpha * circleRgb.y + oneMinusAlpha * accumulatedColor.y;
                    accumulatedColor.z = circleAlpha * circleRgb.z + oneMinusAlpha * accumulatedColor.z;
                    // Keep framebuffer opaque - matches clear behavior and reference impl intent
                    accumulatedColor.w = 1.f;

                } // End if pixel in circle
            } // End loop through circles in shared memory chunk
        } // End check if pixel is within image bounds

        // Wait for all threads to finish processing the current chunk
        // before loading the next chunk into shared memory
        __syncthreads();

    } // End loop over circle chunks

    // After processing all circles, write the final accumulated color to global memory
    // Ensure the write only happens if the pixel is within bounds
    if (globalPixelX < imageWidth && globalPixelY < imageHeight) {
        int pixelOffset = 4 * (globalPixelY * imageWidth + globalPixelX);
        *(float4*)(&cuConstRendererParams.imageData[pixelOffset]) = accumulatedColor;
    }
}

CudaRenderer::CudaRenderer() {
    image = NULL;
    numCircles = 0;
    position = NULL;
    velocity = NULL;
    color = NULL;
    radius = NULL;
    cudaDevicePosition = NULL;
    cudaDeviceVelocity = NULL;
    cudaDeviceColor = NULL;
    cudaDeviceRadius = NULL;
    cudaDeviceImageData = NULL;
}

CudaRenderer::~CudaRenderer() {
    if (image) {
        delete image;
    }
    if (position) {
        delete [] position;
        delete [] velocity;
        delete [] color;
        delete [] radius;
    }
    // Use cudaCheckError wrapper for safety during cleanup
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          // Intentionally not aborting in destructor, just reporting
       }
    }
    if (cudaDevicePosition) cudaCheckError(cudaFree(cudaDevicePosition));
    if (cudaDeviceVelocity) cudaCheckError(cudaFree(cudaDeviceVelocity));
    if (cudaDeviceColor)    cudaCheckError(cudaFree(cudaDeviceColor));
    if (cudaDeviceRadius)   cudaCheckError(cudaFree(cudaDeviceRadius));
    if (cudaDeviceImageData) cudaCheckError(cudaFree(cudaDeviceImageData));
    #undef cudaCheckError // Limit scope of macro
}

const Image* CudaRenderer::getImage() {
    // Wrap CUDA calls with error checking
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          if (abort) exit(code); // Abort on error during critical operations
       }
    }

    // Ensure all GPU work is done before copy
    cudaCheckError(cudaDeviceSynchronize());

    // Copy rendered image from device memory to host
    cudaCheckError(cudaMemcpy(image->data,
                              cudaDeviceImageData,
                              sizeof(float) * 4 * image->width * image->height,
                              cudaMemcpyDeviceToHost));

    #undef cudaCheckError // Limit scope of macro
    return image;
}

void CudaRenderer::setup() {

    // Optional: Add cudaCheckError macro definition here for setup phase
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          if (abort) exit(code); // Abort on error during setup
       }
    }

    int deviceCount = 0;
    std::string name;
    cudaCheckError(cudaGetDeviceCount(&deviceCount));

    printf("---------------------------------------------------------\n");
    printf("Initializing CUDA for CudaRenderer\n");
    printf("Found %d CUDA devices\n", deviceCount);

    for (int i=0; i<deviceCount; i++) {
        cudaDeviceProp deviceProps;
        cudaCheckError(cudaGetDeviceProperties(&deviceProps, i));
        name = deviceProps.name;
        printf("Device %d: %s\n", i, deviceProps.name);
        printf("   SMs:        %d\n", deviceProps.multiProcessorCount);
        printf("   Global mem: %.0f MB\n", static_cast<float>(deviceProps.totalGlobalMem) / (1024 * 1024));
        printf("   CUDA Cap:   %d.%d\n", deviceProps.major, deviceProps.minor);
        printf("   Shared/Blk: %zu KB\n", deviceProps.sharedMemPerBlock / 1024); // Useful info
    }
    printf("---------------------------------------------------------\n");


    // Allocate memory on the device
    cudaCheckError(cudaMalloc(&cudaDevicePosition, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceVelocity, sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceColor,    sizeof(float) * 3 * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceRadius,   sizeof(float) * numCircles));
    cudaCheckError(cudaMalloc(&cudaDeviceImageData, sizeof(float) * 4 * image->width * image->height));


    // Copy data from host to device
    cudaCheckError(cudaMemcpy(cudaDevicePosition, position, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceVelocity, velocity, sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceColor,    color,    sizeof(float) * 3 * numCircles, cudaMemcpyHostToDevice));
    cudaCheckError(cudaMemcpy(cudaDeviceRadius,   radius,   sizeof(float) * numCircles,   cudaMemcpyHostToDevice));


    // Initialize parameters in constant memory.
    GlobalConstants params;
    params.sceneName = sceneName;
    params.numCircles = numCircles;
    params.imageWidth = image->width;
    params.imageHeight = image->height;
    params.position = cudaDevicePosition;
    params.velocity = cudaDeviceVelocity;
    params.color = cudaDeviceColor;
    params.radius = cudaDeviceRadius;
    params.imageData = cudaDeviceImageData;

    cudaCheckError(cudaMemcpyToSymbol(cuConstRendererParams, &params, sizeof(GlobalConstants)));

    // Copy noise lookup tables
    int* permX;
    int* permY;
    float* value1D;
    getNoiseTables(&permX, &permY, &value1D);
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseXPermutationTable, permX, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoiseYPermutationTable, permY, sizeof(int) * 256));
    cudaCheckError(cudaMemcpyToSymbol(cuConstNoise1DValueTable, value1D, sizeof(float) * 256));

    // Copy color lookup table
    float lookupTable[COLOR_MAP_SIZE][3] = {
        {1.f, 1.f, 1.f}, {1.f, 1.f, 1.f}, {.8f, .9f, 1.f},
        {.8f, .9f, 1.f}, {.8f, 0.8f, 1.f},
    };
    cudaCheckError(cudaMemcpyToSymbol(cuConstColorRamp, lookupTable, sizeof(float) * 3 * COLOR_MAP_SIZE));

    #undef cudaCheckError // Limit scope of macro
}

void CudaRenderer::clearImage() {
    // Optional: Add cudaCheckError macro definition here for clearImage phase
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          if (abort) exit(code); // Abort on error during setup
       }
    }

    // Use 2D block dimensions suitable for image processing (e.g., 16x16)
    dim3 blockDim(TILE_DIM_X, TILE_DIM_Y, 1);
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    if (sceneName == SNOWFLAKES || sceneName == SNOWFLAKES_SINGLE_FRAME) {
        kernelClearImageSnowflake<<<gridDim, blockDim>>>();
    } else {
        // Clear to white, fully opaque
        kernelClearImage<<<gridDim, blockDim>>>(1.f, 1.f, 1.f, 1.f);
    }

    // Check for kernel launch errors (asynchronous, caught by synchronize or next sync call)
    cudaCheckError(cudaGetLastError());
    // Ensure clear is finished before proceeding
    cudaCheckError(cudaDeviceSynchronize());

    #undef cudaCheckError // Limit scope of macro
}

void CudaRenderer::advanceAnimation() {
    // Optional: Add cudaCheckError macro definition here for animation phase
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          if (abort) exit(code); // Abort on error during setup
       }
    }

    // Keep 1D block/grid for circle-based animation updates
    dim3 blockDim(256, 1, 1); // Standard block size for 1D problems
    dim3 gridDim((numCircles + blockDim.x - 1) / blockDim.x, 1, 1);

    // Select appropriate animation kernel based on scene
    if (sceneName == SNOWFLAKES) {
        kernelAdvanceSnowflake<<<gridDim, blockDim>>>();
    } else if (sceneName == BOUNCING_BALLS) {
        kernelAdvanceBouncingBalls<<<gridDim, blockDim>>>();
    } else if (sceneName == HYPNOSIS) {
        kernelAdvanceHypnosis<<<gridDim, blockDim>>>();
    } else if (sceneName == FIREWORKS) {
        kernelAdvanceFireWorks<<<gridDim, blockDim>>>();
    } else {
        return; // No animation for other scenes
    }

    // Check for kernel launch errors
    cudaCheckError(cudaGetLastError());
    // Ensure animation step is complete
    cudaCheckError(cudaDeviceSynchronize());

    #undef cudaCheckError // Limit scope of macro
}


void CudaRenderer::render() {
    // Optional: Add cudaCheckError macro definition here for render phase
    #define cudaCheckError(ans) { cudaAssert((ans), __FILE__, __LINE__); }
    inline void cudaAssert(cudaError_t code, const char *file, int line, bool abort=true) {
       if (code != cudaSuccess) {
          fprintf(stderr, "CUDA Error: %s at %s:%d\n", cudaGetErrorString(code), file, line);
          if (abort) exit(code); // Abort on error during setup
       }
    }

    // Launch the new tile-based rendering kernel
    dim3 blockDim(TILE_DIM_X, TILE_DIM_Y, 1); // e.g., 16x16 = 256 threads/block
    dim3 gridDim(
        (image->width + blockDim.x - 1) / blockDim.x,
        (image->height + blockDim.y - 1) / blockDim.y);

    // Calculate required shared memory: pos(3) + radius(1) = 4 floats per circle
    size_t sharedMemBytes = CIRCLE_CHUNK_SIZE * 4 * sizeof(float);
    // printf("Requesting %zu bytes of shared memory per block.\n", sharedMemBytes);
    // NOTE: If sharedMemBytes exceeds device limits (~48KB or 96KB depending on CC),
    //       this launch will fail or need dynamic allocation (more complex).
    //       With CIRCLE_CHUNK_SIZE=256, sharedMemBytes = 256 * 4 * 4 = 4096 bytes (4KB), which is safe.

    kernelRenderTileCentric<<<gridDim, blockDim, sharedMemBytes>>>();

    // Check for kernel launch errors
    cudaCheckError(cudaGetLastError());
    // Ensure rendering is complete before returning control (e.g., before getImage is called)
    cudaCheckError(cudaDeviceSynchronize());

    #undef cudaCheckError // Limit scope of macro
}
