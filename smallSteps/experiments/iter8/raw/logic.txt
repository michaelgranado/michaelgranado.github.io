    <h1>Incremental Plan: Cooperative Tile Processing with Pre-Filtering</h1>
    <p>This plan outlines the steps to implement Solution 4, focusing on correctness at each stage before optimizing. The goal is to first create per-tile lists of potentially overlapping circles and then modify the rendering kernel to use these lists, eventually incorporating shared memory for efficiency.</p>
    <p><strong>Assumption:</strong> You start with the provided correct, unoptimized code (`kernelRenderCirclesTiled` that iterates through all circles but uses `circleInBoxConservative` for tile culling).</p>

    <div class="step">
        <span class="step-title">Step 0: Establish Baseline</span>
        <ul>
            <li>Ensure the current code (`cudaRenderer.cu` containing the pixel-parallel `kernelRenderCirclesTiled` which iterates all circles but performs a `circleInBoxConservative` check) compiles and passes all correctness tests using <code>./checker.py</code>.</li>
            <li>This confirms your starting point is correct, even if slow. Record the performance from the checker as your baseline.</li>
        </ul>
        <p class="check">Verification: Run <code>./checker.py</code>. All tests should pass (no '(F)').</p>
    </div>

    <div class="step">
        <span class="step-title">Step 1: Define Tile Structure and Allocate Count Array</span>
        <ul>
            <li>In <code>CudaRenderer::setup()</code> or a similar initialization spot:
                <ul>
                    <li>Define tile dimensions (e.g., <code>const int TILE_DIM = 16;</code>). Match this to the <code>blockDim</code> used in <code>render()</code>.</li>
                    <li>Calculate the number of tiles in X and Y: <code>numTilesX = (image->width + TILE_DIM - 1) / TILE_DIM;</code>, <code>numTilesY = (image->height + TILE_DIM - 1) / TILE_DIM;</code>. Total tiles: <code>numTiles = numTilesX * numTilesY;</code>.</li>
                    <li>Allocate a global memory array on the GPU to store the *count* of circles overlapping each tile: <code>cudaCheckError(cudaMalloc(&d_tile_circle_counts, numTiles * sizeof(unsigned int)));</code>. Store the pointer (<code>d_tile_circle_counts</code>) and <code>numTiles</code> in the <code>CudaRenderer</code> class.</li>
                    <li>Remember to <code>cudaFree</code> this in the destructor.</li>
                </ul>
            </li>
             <li>No new kernel is added yet. The renderer still functions as in Step 0.</li>
        </ul>
        <p class="check">Verification: Code should compile. Run <code>./checker.py</code>. Correctness and performance should be unchanged from Step 0.</p>
    </div>

    <div class="step">
        <span class="step-title">Step 2: Implement Kernel to Count Tile Overlaps</span>
        <ul>
            <li>Create a new CUDA kernel: <code>__global__ void kernelCountTileOverlaps(...)</code>.
                <ul>
                    <li>Inputs should include circle data (positions, radii), image dimensions, tile dimensions, and the output `d_tile_circle_counts` pointer.</li>
                    <li>Launch configuration: Use one thread per circle (<code>dim3 gridDim((numCircles + 255) / 256, 1); dim3 blockDim(256, 1);</code>).</li>
                    <li>Inside the kernel:
                        <ul>
                            <li>Each thread gets a unique <code>circleIndex</code>.</li>
                            <li>Read the circle's position (<code>p</code>) and radius (<code>rad</code>).</li>
                            <li>Calculate the circle's bounding box in normalized coordinates [0, 1].</li>
                            <li>Determine the range of tile IDs (<code>minTileX, maxTileX, minTileY, maxTileY</code>) that this circle's bounding box potentially overlaps.</li>
                            <li>Loop through all tiles within this range (<code>tileX</code> from <code>minTileX</code> to <code>maxTileX</code>, <code>tileY</code> from <code>minTileY</code> to <code>maxTileY</code>).</li>
                            <li>For each potential tile, calculate its normalized boundaries (<code>tileL, tileR, tileT, tileB</code>).</li>
                            <li>Use the provided <code>circleInBoxConservative(p.x, p.y, rad, tileL, tileR, tileT, tileB)</code> function.</li>
                            <li>If the function returns 1 (overlap is possible), calculate the linear tile ID (<code>tileId = tileY * numTilesX + tileX</code>) and atomically increment the counter for that tile: <code>atomicAdd(&d_tile_circle_counts[tileId], 1);</code>.</li>
                        </ul>
                    </li>
                </ul>
            </li>
            <li>In <code>CudaRenderer::render()</code>, *before* calling <code>kernelRenderCirclesTiled</code>:
                <ul>
                    <li>Initialize the counts array to zero: <code>cudaCheckError(cudaMemset(d_tile_circle_counts, 0, numTiles * sizeof(unsigned int)));</code></li>
                    <li>Launch <code>kernelCountTileOverlaps</code>.</li>
                    <li>Add <code>cudaCheckError(cudaDeviceSynchronize());</code> after the launch to ensure counts are complete before proceeding (can be removed later).</li>
                </ul>
            </li>
        </ul>
        <p class="check">Verification: Code should compile. Run <code>./checker.py</code>. Correctness should still pass (the counts aren't used by the rendering kernel yet). Performance will be worse due to the new kernel launch.</p>
    </div>

    <div class="step">
        <span class="step-title">Step 3: Calculate Offsets and Allocate Global Index List</span>
        <ul>
            <li>Include the Thrust library headers for scan:
                ```cpp
                #include <thrust/device_vector.h>
                #include <thrust/scan.h>
                #include <thrust/execution_policy.h>
                ```
            </li>
            <li>In <code>CudaRenderer::setup()</code>:
                <ul>
                    <li>Allocate memory for the tile offsets: <code>cudaCheckError(cudaMalloc(&d_tile_circle_offsets, numTiles * sizeof(unsigned int)));</code>. Add <code>d_tile_circle_offsets</code> to the class members and free it in the destructor.</li>
                    <li>Add a member variable <code>unsigned int totalOverlaps = 0;</code> and <code>int* d_tile_circle_indices = nullptr;</code> to <code>CudaRenderer</code>.</li>
                </ul>
            </li>
            <li>In <code>CudaRenderer::render()</code>, after <code>kernelCountTileOverlaps</code> and the synchronize:
                <ul>
                    <li>Use Thrust to perform an exclusive scan on <code>d_tile_circle_counts</code> to compute the offsets and store them in <code>d_tile_circle_offsets</code>.
                        ```cpp
                        // Example using Thrust
                        thrust::device_ptr<unsigned int> d_counts_ptr(d_tile_circle_counts);
                        thrust::device_ptr<unsigned int> d_offsets_ptr(d_tile_circle_offsets);
                        thrust::exclusive_scan(thrust::device, d_counts_ptr, d_counts_ptr + numTiles, d_offsets_ptr);
                        ```
                     </li>
                    <li>Calculate the total number of overlaps needed for the index list. This is the sum of all counts, which equals the offset of the (non-existent) last element plus the count of the actual last element.
                        ```cpp
                        unsigned int last_offset, last_count;
                        cudaCheckError(cudaMemcpy(&last_offset, d_tile_circle_offsets + numTiles - 1, sizeof(unsigned int), cudaMemcpyDeviceToHost));
                        cudaCheckError(cudaMemcpy(&last_count, d_tile_circle_counts + numTiles - 1, sizeof(unsigned int), cudaMemcpyDeviceToHost));
                        totalOverlaps = last_offset + last_count; // Store this in the class member if needed across frames, or just use locally.
                        ```
                    </li>
                    <li>Allocate (or reallocate if size changes) the global index list:
                         ```cpp
                         // Basic allocation - potentially reallocate every frame if totalOverlaps changes significantly
                         if (d_tile_circle_indices) cudaFree(d_tile_circle_indices); // Free previous allocation if any
                         cudaCheckError(cudaMalloc(&d_tile_circle_indices, totalOverlaps * sizeof(int)));
                         // A more robust approach might involve checking if the new size exceeds current allocation
                         // and only reallocating if necessary, potentially with some headroom.
                         ```
                    </li>
                     <li>Add <code>cudaCheckError(cudaDeviceSynchronize());</code> after allocation/scan.</li>
                </ul>
            </li>
        </ul>
        <p class="check">Verification: Code compiles. Run <code>./checker.py</code>. Correctness should still pass. Performance will be worse due to scan and allocation overhead.</p>
    </div>

     <div class="step">
        <span class="step-title">Step 4: Implement Kernel to Populate the Global Index List</span>
        <ul>
            <li>Create a new CUDA kernel: <code>__global__ void kernelPopulateTileIndices(...)</code>.
                <ul>
                    <li>Inputs: Circle data, image/tile dimensions, <code>d_tile_circle_counts</code>, <code>d_tile_circle_offsets</code>. Output: <code>d_tile_circle_indices</code>.</li>
                    <li>Need temporary counters for placement. Allocate another GPU array: <code>cudaCheckError(cudaMalloc(&d_temp_tile_counters, numTiles * sizeof(unsigned int)));</code> in `render()` before launching this kernel, initialize it to zeros using `cudaMemset`, and free it after use (or manage it in the class).</li>
                    <li>Launch configuration: One thread per circle (same as `kernelCountTileOverlaps`).</li>
                    <li>Inside the kernel:
                        <ul>
                            <li>Each thread gets a unique <code>circleIndex</code>.</li>
                            <li>Read circle position (<code>p</code>) and radius (<code>rad</code>).</li>
                            <li>Repeat the logic from <code>kernelCountTileOverlaps</code> to find the range of potentially overlapping tiles and loop through them.</li>
                            <li>For each tile <code>t</code> (with linear ID <code>tileId</code>) that passes the <code>circleInBoxConservative</code> check:
                                <ul>
                                    <li>Atomically increment the temporary counter for this tile and get the previous value (local offset): <code>unsigned int localOffset = atomicAdd(&d_temp_tile_counters[tileId], 1);</code></li>
                                    <li>Read the global offset for this tile: <code>unsigned int globalOffset = d_tile_circle_offsets[tileId];</code></li>
                                    <li>Calculate the final index in the global list: <code>unsigned int finalIndex = globalOffset + localOffset;</code></li>
                                    <li>Write the current circle's index into the list: <code>d_tile_circle_indices[finalIndex] = circleIndex;</code></li>
                                </ul>
                            </li>
                        </ul>
                    </li>
                </ul>
            </li>
            <li>In <code>CudaRenderer::render()</code>, after calculating offsets and allocating <code>d_tile_circle_indices</code>:
                <ul>
                    <li>Allocate and zero `d_temp_tile_counters`.</li>
                    <li>Launch <code>kernelPopulateTileIndices</code>.</li>
                    <li>Free `d_temp_tile_counters`.</li>
                    <li>Add <code>cudaCheckError(cudaDeviceSynchronize());</code> after the launch.</li>
                </ul>
            </li>
        </ul>
        <p class="check">Verification: Code compiles. Run <code>./checker.py</code>. Correctness should still pass. Performance likely worse again.</p>
    </div>

    <div class="step">
        <span class="step-title">Step 5: Modify Rendering Kernel to Use Per-Tile Lists (No Shared Memory)</span>
        <ul>
            <li>Modify the existing <code>kernelRenderCirclesTiled</code>:
                <ul>
                    <li>Add the new pointers (<code>d_tile_circle_counts</code>, <code>d_tile_circle_offsets</code>, <code>d_tile_circle_indices</code>) as kernel parameters.</li>
                    <li>Inside the kernel, each thread still calculates its <code>pixelX</code>, <code>pixelY</code>.</li>
                    <li>Calculate the linear tile ID for the block: <code>int tileX = blockIdx.x; int tileY = blockIdx.y; int numTilesX = gridDim.x; int tileId = tileY * numTilesX + tileX;</code> (Assuming gridDim matches tile layout).</li>
                    <li>Read the count and offset for this block's tile: <code>unsigned int count = d_tile_circle_counts[tileId];</code>, <code>unsigned int offset = d_tile_circle_offsets[tileId];</code>.</li>
                    <li><strong>Replace</strong> the main loop <code>for (int circleIndex = 0; circleIndex < cuConstRendererParams.numCircles; circleIndex++)</code> with:
                        ```cuda
                        for (int i = 0; i < count; i++) {
                            int circleIndex = d_tile_circle_indices[offset + i];
                            // ... rest of the logic using circleIndex ...
                        }
                        ```
                    </li>
                    <li><strong>Remove</strong> the <code>circleInBoxConservative</code> check inside this loop (it's redundant now, as the list only contains circles potentially overlapping this tile).</li>
                    <li>The rest of the pixel processing logic (calculating <code>pixelCenterNorm</code>, calling <code>shadePixel</code>, accumulating color, writing final pixel) remains the same.</li>
                </ul>
            </li>
             <li>In <code>CudaRenderer::render()</code>, update the launch call to <code>kernelRenderCirclesTiled</code> to pass the new arguments.</li>
        </ul>
        <p class="check">Verification: Run <code>./checker.py</code>. <strong>This is the first step where correctness relies heavily on the pre-filtering being correct.</strong> If it passes, you should see a significant performance improvement over the baseline, especially on scenes with many circles.</p>
    </div>

    <div class="step">
        <span class="step-title">Step 6: Introduce Shared Memory for Circle Indices and Data</span>
        <ul>
            <li>Modify <code>kernelRenderCirclesTiled</code> again:
                <ul>
                    <li>Define a maximum number of circles a tile might handle in shared memory (e.g., <code>#define MAX_CIRCLES_PER_TILE_SHARED 1024</code>). This needs to be less than the available shared memory per block allows, considering indices and potentially position/radius data.</li>
                    <li>Declare shared memory arrays:
                        ```cuda
                        __shared__ int s_tile_circle_indices[MAX_CIRCLES_PER_TILE_SHARED];
                        // Optional: Also load position/radius if beneficial and fits
                        // __shared__ float3 s_positions[MAX_CIRCLES_PER_TILE_SHARED];
                        // __shared__ float s_radii[MAX_CIRCLES_PER_TILE_SHARED];
                        ```
                    </li>
                    <li>Get <code>tileId</code>, <code>count</code>, and <code>offset</code> as before.</li>
                    <li>Implement cooperative loading of circle indices (and optionally data) from global (<code>d_tile_circle_indices</code>, <code>cuConstRendererParams.position</code>, etc.) into the shared memory arrays (<code>s_tile_circle_indices</code>, etc.). This requires a loop where threads in the block collectively load chunks of data up to `count` (or `MAX_CIRCLES_PER_TILE_SHARED`, whichever is smaller).
                        ```cuda
                        // Example loading loop (load only indices first)
                        int numToLoad = min((int)count, MAX_CIRCLES_PER_TILE_SHARED); // Handle cases where count > max shared size
                        int tid = threadIdx.x + blockDim.x * threadIdx.y; // Linear thread ID within block
                        int threadsPerBlock = blockDim.x * blockDim.y;

                        for (int i = tid; i < numToLoad; i += threadsPerBlock) {
                            s_tile_circle_indices[i] = d_tile_circle_indices[offset + i];
                            // if loading position/radius:
                            // int globalCircleIdx = s_tile_circle_indices[i];
                            // s_positions[i] = *(float3*)&(cuConstRendererParams.position[3 * globalCircleIdx]);
                            // s_radii[i] = cuConstRendererParams.radius[globalCircleIdx];
                        }
                        __syncthreads(); // Ensure all threads finish loading before proceeding
                        ```
                    </li>
                    <li>Modify the main processing loop to iterate up to `numToLoad` and read from shared memory:
                        ```cuda
                        for (int i = 0; i < numToLoad; i++) {
                            int circleIndex = s_tile_circle_indices[i];
                            // Get position/radius from shared memory if loaded, else from global using circleIndex
                            // float3 p = s_positions[i]; // If loaded
                            // float rad = s_radii[i]; // If loaded
                            float3 p = *(float3*)&(cuConstRendererParams.position[3 * circleIndex]); // If not loaded into shared
                            float rad = cuConstRendererParams.radius[circleIndex]; // If not loaded into shared

                            shadePixel(circleIndex, pixelCenterNorm, p, accumulatedColor);
                        }
                        ```
                     <li><strong>Important:</strong> If <code>count > MAX_CIRCLES_PER_TILE_SHARED</code>, you need an outer loop that loads and processes chunks of `MAX_CIRCLES_PER_TILE_SHARED` circles until all `count` circles for the tile are processed. Each chunk involves a load phase, `__syncthreads()`, and a processing phase.</li>
                </ul>
            </li>
        </ul>
        <p class="check">Verification: Run <code>./checker.py</code>. Correctness must still hold. Performance should improve further due to reduced global memory traffic in the main rendering loop, assuming shared memory limits aren't severely exceeded.</p>
